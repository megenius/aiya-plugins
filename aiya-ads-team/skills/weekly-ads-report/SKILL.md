# weekly-ads-report (รายงานแอดรายสัปดาห์)

ตอบคำถามเดียว: **สัปดาห์นี้แอดเป็นยังไง สรุปเป็นภาษาคนจากตัวเลขจริงเท่านั้น**

## หลักคิด

- ตัวเลขทุกตัวมาจากเครื่องมือ (`mkt_outcome_list`) ห้ามประมาณเองหรือปัดให้ดูสวย
- **ท่อข้อมูลวันนี้ยังไม่มี CPA และไม่มี ROAS** ห้ามพูดราวกับรู้ ให้บอกว่ายังไม่มีตัวเลขต่อออเดอร์
- ดึงผลไม่ได้ ต้องบอกว่าดึงไม่ได้พร้อมสาเหตุ ห้ามรายงานเป็นใช้ไป 0 บาท (เจ้าของจะสรุปผิดว่าแอดหยุดเอง)
- บอกช่วงเวลาที่นับเสมอ และเทียบกับสัปดาห์ก่อนหน้า ไม่มีสัปดาห์ก่อนให้เทียบ บอกตรงๆ ว่ายังไม่มีข้อมูลเทียบ

## ขั้นตอน

1. ดึงผลจริงของสัปดาห์นี้และสัปดาห์ก่อน (`mkt_outcome_list`)
2. สรุปยอดใช้จ่ายรวม ต้นทุนต่อคลิกเฉลี่ย และกลุ่มที่ผลดี/ผลแย่ที่สุด
3. เทียบกับสัปดาห์ก่อนเป็นเปอร์เซ็นต์ ถ้าไม่มีข้อมูลเก่า บอกว่า "ยังไม่มีสัปดาห์ก่อนให้เทียบ"
4. ปิดท้ายด้วยสิ่งที่ควรพิจารณาต่อ (ย้ายงบ / ทดสอบใหม่ / ปล่อยไว้เหมือนเดิม) โดยไม่ชี้ขาดแทนเจ้าของ

## รูปแบบผลลัพธ์

สรุป 3 บรรทัดภาษาคน ตามด้วยตารางราย adset (งบ | ต้นทุนต่อคลิก | เทียบสัปดาห์ก่อน)
ปิดท้ายว่าดึงข้อมูลได้ครบหรือมีส่วนไหนดึงไม่ได้
