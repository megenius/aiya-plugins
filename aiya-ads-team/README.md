# aiya-ads-team

ปลั๊กอิน Claude Cowork / Claude Code สำหรับทีมโฆษณา AI ของร้านค้า AIYA
ทีมนี้ **เสนอได้ กดเองไม่ได้** ทุกอย่างที่ใช้เงินจริงต้องให้เจ้าของกดเองที่หน้าโต๊ะแอด `/ads`

## สิ่งที่อยู่ในปลั๊กอิน

### Connector (1 ตัว)

| ชื่อ | URL | ใช้ทำอะไร |
|---|---|---|
| `aiya-agents` | `https://mcp.aiya.me/mcp` | อ่านแผนสัปดาห์ที่อนุมัติแล้วและผลลัพธ์จริงผ่าน `mkt_plan_get` / `mkt_outcome_list` / ดูตัวอย่างแคมเปญผ่าน `mkt_ads_preview_run` |

เป็น HTTP + OAuth ยังไม่ล็อกอินจะได้ 401 ล็อกอินผ่าน `/mcp` ใน Claude Code

### Agents (3 ตำแหน่ง)

ชื่อไฟล์ = id ตำแหน่งเดียวกับสมองกลางของ AIYA (`apps/api/src/team-ads.ts`)

- โบว์ (ads_lead) หัวหน้าทีม อ่านผลเมื่อวาน เสนอปรับ ดูตัวอย่างแคมเปญจากแผนที่อนุมัติ
- ไหม (ads_budget) คุมงบ ย้ายงบระหว่างกลุ่มโฆษณาจากผลจริง ห้ามขอเพิ่มงบรวม
- เจ (ads_abtest) ทดสอบ A/B ออกแบบการทดสอบที่เทียบกันได้จริง ตัดสินผู้ชนะเมื่อข้อมูลพอเท่านั้น

**ทั้งสามตำแหน่งยังไม่มีงานประจำอัตโนมัติ** (เบื้องหลังยังถือตั๋วโฆษณาของร้านไม่ได้) สั่งงานผ่านแชทสดได้ทันที

### Skills (6 ใบ)

| Skill | ตอบคำถาม |
|---|---|
| `campaign-structure` | ก่อนเริ่มแคมเปญ ควรแบ่ง adset/ad แบบไหน |
| `budget-pacing` | งบสัปดาห์นี้เดินเร็ว/ช้าไป ควรย้ายงบไหน |
| `ab-test-plan` | ออกแบบการทดสอบสองไอเดียให้เทียบกันได้จริง |
| `creative-scorecard` | ครีเอทีฟชิ้นนี้ผ่านเช็กลิสต์พื้นฐานไหม |
| `audience-brief` | แคมเปญนี้ควรพูดกับใคร |
| `weekly-ads-report` | สรุปผลแอดสัปดาห์นี้เป็นภาษาคน |

### Commands (1 คำสั่ง)

- `/ads-report` สรุปผลแอดสัปดาห์นี้ผ่านโบว์ (ads_lead)

## ติดตั้ง

### Claude Cowork

1. เปิดหน้าตั้งค่า Plugin ของ Cowork
2. เพิ่ม marketplace จาก repo นี้: `megenius/aiya-plugins`
3. ติดตั้งปลั๊กอิน `aiya-ads-team`

### Claude Code (CLI)

```
/plugin marketplace add megenius/aiya-plugins
/plugin install aiya-ads-team@aiya
```

ชื่อ `aiya` มาจากชื่อ marketplace ใน `plugins/.claude-plugin/marketplace.json` ของ repo นี้

## กติกาความปลอดภัย

- ทีมนี้เป็นระดับอำนาจ 2 เท่านั้น ไม่ยิงแอดเอง ไม่ใช้เงินเอง ทุกข้อเสนอจบที่คิวรออนุมัติของเจ้าของร้าน
- แคมเปญที่ระบบสร้างเป็น PAUSED เสมอ เปิดใช้งานจริงต้องให้เจ้าของกดเองที่ `/ads`
- เพดานงบต่อช่องคือ ฿1,000/วัน เกินเพดาน ระบบตัดลงมาและบอกตรงๆ ไม่ตัดเงียบ
- ท่อข้อมูลวันนี้ยังไม่มี CPA และไม่มี ROAS ห้ามพูดราวกับรู้
- ดึงผลไม่ได้ต้องบอกว่าดึงไม่ได้ ห้ามรายงานเป็นใช้ไป 0 บาท
