# /leak

หารอยรั่วของร้าน $ARGUMENTS โดยให้ agent `analyst` เรียก skill **รอยรั่ว (leak)**

## ขั้นตอน

1. ให้ `analyst` เรียก `mkt_listen_run` ดึงยอดห้องแชทเปิดใหม่ ยอดทักเข้ามา และห้องค้างไม่ได้ตอบ เทียบช่วงก่อนหน้า
2. เขียนฟันเนล 6 ขั้น ติดป้ายกำกับทุกขั้น (`วัดจากระบบ` / `เจ้าของประเมิน` / `ยังไม่รู้`) ตามกฎของ skill ห้ามวาดกรวยให้ครบถ้าข้อมูลไม่ครบ
3. ชี้รอยรั่วหนึ่งจุดจากขั้นที่ `วัดจากระบบ` เท่านั้น พร้อมหนึ่งการกระทำที่ทำได้สัปดาห์นี้
4. บอกสิ่งที่ต้องเริ่มบันทึกจากวันนี้ ถ้าขั้นไหนยังวัดไม่ได้

ห้ามคำนวณอัตราแปลงระหว่างขั้นที่ไม่ได้วัดจากระบบทั้งคู่ ห้ามเสนอหน้าจอ/ระบบใหม่ที่ยังไม่มีวันนี้
