# /owner-summary

สรุปสัปดาห์นี้ให้เจ้าของร้าน $ARGUMENTS ให้ agent `marketing-lead` คุมภาพรวม โดยให้ `analyst` ดึงตัวเลขและ `reviewer` ตรวจก่อนส่ง

## ขั้นตอน

1. ให้ `analyst` เรียก skill **รอยรั่ว (leak)** ดูตัวเลขฟันเนลสัปดาห์นี้เทียบสัปดาห์ก่อน
2. ให้ `analyst` เรียก `mkt_outcome_list` ดูว่ามีการทดลองใดถึงกำหนดปิดหรือยัง แล้วรายงานผล
3. ถ้าสัปดาห์นี้มีการยิงแอด ให้ `ads-buyer` อ่านผลแอดล่าสุดมาด้วย (งานอ่านอย่างเดียว)
4. ให้ `reviewer` ตรวจตัวเลขและป้ายกำกับทั้งหมดก่อนสรุป (ราคา/ตัวเลขมีที่มาไหม ป้าย `ยังไม่รู้` ครบไหม)
5. `marketing-lead` สรุปเป็นภาษาคน **ไม่เกิน 5 ข้อ**: ตัวเลขฟันเนล, ผลการทดลอง (หรือ "ยังบอกไม่ได้"), ผลแอด (ถ้ามี), กองลูกค้าที่ควรตามสัปดาห์นี้, และสิ่งที่ต้องทำต่อ 1 อย่าง

เขียนเป็นภาษาคนธรรมดา ไม่ใช้ศัพท์การตลาด ตัวเลขทุกตัวต้องมาจากเครื่องมือจริงพร้อมป้ายกำกับ ห้ามเดาหรือสัญญาตัวเลขที่ไม่มีข้อมูล

ถ้าขั้นไหนทำไม่ได้เพราะยังไม่ได้เชื่อมต่อระบบ (เพจ Facebook / LINE OA / บัญชีโฆษณา / ระบบขาย / ระบบอีเวนต์) ให้บอกเป็นภาษาคนว่าต้องเชื่อมต่ออะไรและกดเชื่อมต่อยังไง (ดูคำแปลชื่อระบบที่ `reference/onboarding.md`) **ห้ามเอ่ยชื่อ connector (`aiya-*`), ชื่อ tool (`xxx_yyy`), หรือชื่อ agent ภายใน** เช่น `analyst`/`reviewer`/`marketing-lead` กับเจ้าของร้าน และ**ห้ามใส่หมายเหตุทางเทคนิคเกี่ยวกับตัวระบบเอง** (เช่น เซสชันรันแบบอัตโนมัติ กดปุ่มแทนไม่ได้เพราะเหตุผลทางเทคนิค) ในคำตอบที่ส่งให้เจ้าของร้าน บอกแค่สิ่งที่เจ้าของร้านต้องทำเองเท่านั้น
