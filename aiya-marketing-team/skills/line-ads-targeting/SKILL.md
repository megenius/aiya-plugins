# line-ads-targeting (เลือกกลุ่มเป้าหมาย LINE Ads)

อ้างอิงจาก line-ads-mcp โดย Praphat Srisuma (Spark Factor) Apache-2.0

ตอบคำถามเดียว: **แคมเปญนี้ควรเล็งไปหาใคร และควรผสม interest/behavior แบบไหนถึงจะเป็น "กลุ่มเป้าหมายจริง" ไม่ใช่แค่กองอินเทอเรสต์ที่ดูเกี่ยวข้อง**

## ความจริงที่ต้องบอกเจ้าของร้านก่อนเสมอ (ห้ามข้าม)

- 🔴 **ระบบ AIYA ยังไม่มีเครื่องมือดึงรายการ interest/behavior โค้ดสดจาก LINE API** ตัวอย่างโค้ดใน
  สกิลนี้เป็นภาพรวมจาก snapshot ของ line-ads-mcp (verified 2026-05-13, objective GAIN_FRIENDS,
  ประเทศไทย) เท่านั้น **โค้ดจริงอาจเปลี่ยนหรือมีมากกว่านี้** ก่อนตั้งค่าจริงต้องไปเช็คที่หน้า
  Interest ใน LINE Ads Manager เอง
- กติกาการคิด (Need/Ability/Life Stage) ใช้ได้เสมอไม่ว่าโค้ดจะเปลี่ยนไปแค่ไหน สิ่งที่ต้องจำคือ
  **วิธีคิด** ไม่ใช่เลขโค้ด

## เมื่อไหร่ใช้

- เจ้าของบอกว่า "อยากยิงหาคนกลุ่มนี้" แต่ยังไม่มีนิยามชัด
- เจ้าของกำลังจะติ๊ก interest หลายอันที่ "ดูเกี่ยวข้องกับสินค้า" รวมกันเป็นกลุ่มเดียว
- เจ้าของถามว่ามี signal อะไรของ LINE ที่ใช้เจาะกลุ่มได้บ้าง (follower เพจคู่แข่ง, OpenChat, LINE TODAY)

## กติกาที่ห้ามข้าม: หา Customer Avatar ก่อนเปิดหน้า Interest

**ห้ามเปิดหน้า interest แล้วเริ่มติ๊กทันที** ต้องตอบ 3 คำถามนี้ก่อนเสมอ

| ชั้น | คำถามที่ถามเจ้าของ | ตัวอย่าง (บ้านเดี่ยว 10 ล้าน) |
|---|---|---|
| Need | ลูกค้ากำลังมองหาสินค้า/บริการนี้อยู่ไหม แสดงออกยังไง | มองหาบ้าน / สนใจอสังหาริมทรัพย์ |
| Ability | มีกำลังซื้อระดับไหน สนใจเรื่องการเงินแบบไหน | สนใจการลงทุน / กำลังซื้อสูง |
| Life Stage | ช่วงชีวิตแบบไหน (ครอบครัว โสด นักศึกษา) | มีครอบครัว แต่งงานแล้ว มีลูก |

ทำไมต้องแยก 3 ชั้น: สินค้าราคาสูงที่พังบ่อยคือกองทุก interest ที่ "ดูเกี่ยวข้อง" ไว้กลุ่มเดียว
(บ้านและสวน + อสังหา + รถยนต์ + ครอบครัว + ท่องเที่ยว) แล้วยิงงบหลักแสน/เดือนแต่หาลูกค้าจริงไม่เจอ
เพราะเริ่มจาก interest ก่อน customer avatar

## วิธีผสมโค้ด (ตัวอย่างจาก snapshot 2026-05)

หลักคิด: แต่ละชั้น (Need/Ability/Life Stage) ผสม 3-5 โค้ดแบบ **OR กันภายในชั้น**
แล้วนำแต่ละชั้น **AND ข้ามชั้น** (ไม่ใช่โยนโค้ดทั้งหมดรวมเป็น OR กลุ่มเดียว)

ตัวอย่างบ้านเดี่ยว 10-15 ล้านบาท (จาก snapshot line-ads-mcp):

| ชั้น | Insight | โค้ดตัวอย่าง (OR กันในชั้น) |
|---|---|---|
| Need | สนใจอสังหาริมทรัพย์ | บ้านและสวน · ผู้ติดตาม OA อสังหาริมทรัพย์ · OpenChat ชุมชนผู้พักอาศัย |
| Ability | มีกำลังซื้อ | การเงิน · การลงทุน · กำลังซื้อสูง · OpenChat การเงินและการลงทุน |
| Life Stage | มีครอบครัว | ครอบครัว · การเลี้ยงดูบุตร · งานแต่งงาน |

**คำเตือน 2 ทาง (ผิดได้ทั้งสองแบบ):**
1. อย่ากองทุก interest ที่ดูเกี่ยวข้องไว้กลุ่มเดียวแบบ OR ทั้งหมด (ไม่ตรงกับ customer avatar จริง)
2. อย่าใส่ชั้นละ 1-2 โค้ดแล้วจำกัดจนแคบเกิน (audience เหลือหลักหมื่นทั้งที่ไม่จำเป็น) แต่ละชั้น
   ควรมีอย่างน้อย 3 โค้ดผสมกันเพื่อให้สะท้อนกลุ่มจริง

## สัญญาณจากระบบนิเวศ LINE (ใช้เสริมชั้นไหนก็ได้)

- ผู้ติดตามบัญชีทางการ LINE (OA) ตามหมวดธุรกิจ เช่น อสังหาริมทรัพย์, ประกัน, การศึกษา
- หัวข้อ LINE OpenChat เช่น การเงินและการลงทุน, ความงามและสุขภาพ, ยานยนต์
- ผู้ใช้งานบริการ LINE เช่น LINE วอลเล็ต (มักสัมพันธ์กับกำลังซื้อ/ความคุ้นเคยดิจิทัล)
- ประเภทข่าวที่อ่านใน LINE TODAY เช่น ธุรกิจ-เศรษฐกิจ, การลงทุน, ไลฟ์สไตล์

ตัวอย่างการแมปธุรกิจทั่วไป (จาก snapshot): เจ้าของกิจการ/SME → หมวดอาชีพและธุรกิจ,
พ่อค้าแม่ค้าออนไลน์ → ธุรกิจ + ช้อปปิ้ง, คลินิกความงาม → ธุรกิจ + ความงาม, ร้านอาหาร → ธุรกิจ + อาหาร

## เช็คขนาดกลุ่มเป้าหมายก่อนสรุปแผน

อย่าแคบจนเหลือหลักหมื่นด้วยความเชื่อว่ายิ่งแคบยิ่งแม่น ให้ประมาณคร่าวๆ ด้วยสูตรอ้างอิง
`ขนาดกลุ่มเป้าหมาย ≈ งบ ÷ CPM × 5,000` แล้วเทียบกับตัวเลขจริงที่หน้า LINE Ads Manager ก่อนยืนยันแผน
(ระบบ AIYA ยังไม่มีเครื่องมือดึงขนาด audience สด)

## ขั้นตอน

1. หา Customer Avatar ก่อนเสมอ (Need → Ability → Life Stage) ห้ามข้ามไปเลือก interest ตรงๆ
2. ผสมโค้ดตัวอย่างของแต่ละชั้น (OR ในชั้น, AND ข้ามชั้น) เป็นแผนร่างให้เจ้าของดู
3. เตือนว่าโค้ดจริงต้องไปยืนยันที่ LINE Ads Manager เพราะ snapshot อาจไม่ตรงกับของจริงวันนี้แล้ว
4. เช็คขนาดกลุ่มเป้าหมายคร่าวๆ ก่อนสรุป อย่าให้แคบเกินไปโดยไม่ตั้งใจ

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามยืนยันว่าโค้ด/รหัส interest ในสกิลนี้ตรงกับของจริงวันนี้แน่นอน (เป็น snapshot 2026-05)
- ห้ามข้ามขั้น Customer Avatar ไปเลือก interest ตรงๆ แม้เจ้าของจะรีบ
- ห้ามเดาขนาดกลุ่มเป้าหมายเป็นตัวเลขนิ่งๆ โดยไม่บอกว่าเป็นการประมาณ

## เกี่ยวข้อง

- วัตถุประสงค์แคมเปญที่ควรเลือกก่อนคิดเรื่อง targeting ดูที่ `line-ads-basics`
- นำกลุ่มเป้าหมายไปคำนวณงบ/บิด ดูที่ `line-ads-bidding-budget`
- ขั้นตอนเต็มตั้งแต่เริ่มถึงสร้างแคมเปญ ดูที่ `line-ads-campaign-workflow`
- แบ่งกลุ่มลูกค้าเดิมของร้าน (คนละเรื่องกับ interest ของ LINE) ดูที่ `who-first`
