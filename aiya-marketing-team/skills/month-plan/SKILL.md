# month-plan (เป้าธุรกิจ → แผนเดือน)

ตอบคำถามเดียว: **เดือนนี้ร้านควรทำอะไรบ้าง เรียงเป็นสัปดาห์ พูดเรื่องอะไร กับใคร ช่องไหน งบเท่าไหร่**

ห่วงโซ่ที่ skill นี้เดิน: **เป้าธุรกิจ → ธีมเดียว → ปฏิทิน 4 สัปดาห์ → ช่องทาง → งบ**
ทุกขั้นต้องมีที่มาจากเครื่องมือจริงหรือคำตอบของเจ้าของ ห้ามข้ามขั้นแม้ผู้ใช้เร่ง

## ขั้นตอน

1. **ฟังเป้าธุรกิจ** ถามเจ้าของก่อนว่าเดือนนี้อยากได้ผลอะไร (ดูคำถามข้อ 1 ด้านล่าง) ถ้าเจ้าของให้เป้ามาแล้วในคำสั่ง ใช้เป้านั้นได้เลยไม่ต้องถามซ้ำ

2. **เคาะธีมเดียว** เรียก skill **จุดเด็ด (winning-zone)** หาจุดขาย 1-2 ข้อที่ตรงกับเป้าธุรกิจที่สุด รวมเป็น **ธีมเดียวของเดือน** (ไม่ใช่หลายธีมพร้อมกัน) ถ้าเป้าธุรกิจกับจุดขายที่ระบบเห็นไม่ตรงกัน บอกเจ้าของตรงๆ ว่าอาจต้องเลือกอย่างใดอย่างหนึ่ง

3. **เลือกใครก่อน** เรียก skill **ใครก่อน (who-first)** เลือกกองลูกค้าที่จะโฟกัสของเดือนนี้ ให้ตรงกับธีมที่เคาะไว้ (เช่น ธีม "ดึงลูกค้าเก่ากลับมา" ควรโฟกัสกอง "ตามกลับด่วน")

4. **เช็ครอยรั่วก่อนเดินหน้า** เรียก skill **รอยรั่ว (leak)** ถ้ามีรอยรั่วใหญ่ (เช่น ห้องค้างไม่ได้ตอบเยอะ) ให้ใส่เป็นงานสัปดาห์แรกของแผนก่อนงานหาลูกค้าใหม่ แก้ของเดิมก่อนเติมของใหม่

5. **เช็ควันสำคัญ** เรียก skill **thai-calendar** ดูว่าเดือนนี้มีเทศกาล/วันสำคัญที่เกี่ยวกับร้านไหม ถ้ามี ให้ผูกเข้ากับสัปดาห์ที่เหมาะ (เตรียมเนื้อหาก่อนวันจริงตามเช็กลิสต์ของ skill นั้น)

6. **ประกาศผลลัพธ์ก่อนแตกสัปดาห์** เรียก skill **ลองแล้วรู้ (test-and-learn)** เช็คว่ามีใบประกาศผลลัพธ์ (`mkt_outcome`) ไหม ถ้าไม่มี บอกเจ้าของให้ประกาศก่อน ทุกสัปดาห์ในแผนต้องชี้ได้ว่าพาไปสู่ใบประกาศข้อไหน

7. **แตกเป็นปฏิทิน 4 สัปดาห์** แต่ละสัปดาห์มี: หัวข้อ/ธีมย่อย (ต้องอยู่ในกรอบธีมเดือน), ช่องทาง (เพจ/สตอรี่/ตอบแชท), งานหลักไม่เกิน 1-2 ชิ้น, ชี้กลับไปที่กองลูกค้า/ใบประกาศที่เกี่ยวข้อง

8. **ตัดสินเรื่องงบ** ถ้าเดือนนี้มีงบโฆษณา ให้ชี้ไปที่ skill **safe-ads** สำหรับขั้นเตรียม/ยืนยัน/ทางไปหน้าโต๊ะแอด ห้ามพูดเหมือนว่า month-plan สร้างแคมเปญให้ได้เอง

9. งานที่ต้องร่างโพสต์จริง ส่งต่อให้ skill **brand-content** และ agent `page-admin` ตัว month-plan เองไม่ร่างเนื้อหาเอง

## คำถามที่ถามเจ้าของร้าน (ไม่เกิน 3 ข้อ แล้วรอคำตอบ)

1. เดือนนี้อยากได้ผลอะไรที่สุด (ลูกค้าใหม่ / ลูกค้าเก่ากลับมา / ขายของที่ค้างสต๊อก / อื่นๆ) เลือกได้ข้อเดียว
2. เดือนนี้มีงบโฆษณาไหม ถ้ามี ประมาณเท่าไหร่ต่อวัน
3. มีเหตุการณ์ของร้านเดือนนี้ที่ระบบไม่รู้ไหม (เปิดสาขาใหม่ สินค้าใหม่ ปิดร้านบางวัน)

## รูปแบบผลลัพธ์

1. **ธีมของเดือน** (1 บรรทัด + เหตุผลจากจุดเด็ด)
2. **กองลูกค้าที่โฟกัส** (จาก who-first)
3. ตารางปฏิทิน 4 แถว คอลัมน์: สัปดาห์ | หัวข้อย่อย | ช่องทาง | งานหลัก | ชี้กลับไปที่ (กองลูกค้า/ใบประกาศ)
4. **งบ** บรรทัดเดียว (มี/ไม่มีงบโฆษณา ถ้ามีชี้ไปที่ skill safe-ads)
5. **สิ่งที่ต้องแก้ก่อน** ถ้ามีรอยรั่วใหญ่จาก leak

## ประตูอนุมัติ (อะไรต้องให้คนกดก่อน)

- วางแผนและเรียกเครื่องมือดูตัวเลข: P0/P1 ทำได้ทันที แสดงแผนให้ดูก่อนเสมอ
- แผนทั้งเดือนต้องได้เจ้าของ **อนุมัติเป็นชุดก่อน** ถึงจะเริ่มร่างเนื้อหาจริงหรือดูตัวอย่างแคมเปญต่อ (ดู `approval-gate` - วางแผนเป็น P1 แต่ทุกอย่างที่ตามมาแยกระดับของตัวเอง)
- โพสต์จริง ตอบลูกค้าจริง หรือใช้เงินโฆษณา **ไม่ทำที่นี่** ส่งต่อไปยัง skill ที่เกี่ยวแล้วผ่าน `approval-gate` ของมันเอง

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามมีมากกว่า 1 ธีมหลักต่อเดือน ถ้าอยากทำหลายเรื่อง ให้เลือกธีมหลักแล้วเก็บที่เหลือไว้เดือนถัดไป
- ทุกสัปดาห์ในปฏิทินต้องชี้ได้ว่าพาไปสู่กองลูกค้าหรือใบประกาศผลลัพธ์ข้อไหน ชี้ไม่ได้ = ตัดออก
- ห้ามข้ามขั้นตรวจรอยรั่วแล้วกระโดดไปหาลูกค้าใหม่ทันที ถ้ามีรอยรั่วใหญ่ต้องแก้ก่อน
- ห้ามสัญญาตัวเลขผลลัพธ์ (ยอดขาย จำนวนลูกค้าใหม่) ที่ไม่มีข้อมูลรองรับ

### เดวิลส์แอดโวเคตก่อนสรุป

ก่อนส่งแผนสุดท้าย ให้ตรวจ 3 ข้อนี้
1. ธีมของเดือนตรงกับเป้าธุรกิจที่เจ้าของบอกจริงไหม หรือหลุดไปทำเรื่องที่ทีมอยากทำเอง
2. มีสัปดาห์ไหนที่ชี้กลับไปที่กองลูกค้า/ใบประกาศไม่ได้ แต่ยังใส่ไว้ในแผนอยู่ไหม
3. ถ้ามีรอยรั่วใหญ่จาก leak แผนนี้แก้จุดนั้นก่อน หรือข้ามไปทำเรื่องใหม่ทั้งที่ของเดิมยังรั่วอยู่
