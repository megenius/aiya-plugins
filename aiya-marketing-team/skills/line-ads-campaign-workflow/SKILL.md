# line-ads-campaign-workflow (ลำดับขั้นตอนตั้งบัญชี/วางแผนแคมเปญ LINE Ads)

อ้างอิงจาก line-ads-mcp โดย Praphat Srisuma (Spark Factor) Apache-2.0

ตอบคำถามเดียว: **ถ้าจะช่วยเจ้าของวางแผนตั้งบัญชีหรือแคมเปญ LINE Ads ตั้งแต่ศูนย์ ควรถามอะไรก่อนหลัง**

## ความจริงที่ต้องบอกเจ้าของร้านก่อนเสมอ (ห้ามข้าม)

- 🔴 **ทุกขั้นตอนในสกิลนี้จบที่ "เจ้าของไปทำต่อเองที่ LINE Ads Manager"** ระบบ AIYA วันนี้ไม่มี
  เครื่องมือที่ตั้งบัญชี สร้างแคมเปญ หรือยิงโฆษณา LINE แทนได้เลยสักขั้นตอนเดียว
- ลำดับคำถามด้านล่างมาจากขั้นตอนของ line-ads-mcp (บันทึก 2026-07) ใช้เป็นเช็กลิสต์คุยกับเจ้าของ
  ไม่ใช่แบบฟอร์มที่ระบบจะกรอกให้อัตโนมัติ

## เมื่อไหร่ใช้

- เจ้าของยังไม่เคยมีบัญชี LINE Ads เลย และถามว่าต้องเริ่มยังไง
- เจ้าของมีบัญชีอยู่แล้วแต่ไม่รู้ว่าต้องถามอะไรก่อนเริ่มวางแผนแคมเปญ
- ต้องสรุปเช็กลิสต์ทั้งชุดให้เจ้าของก่อนนัดคุยกับทีมออกแบบ/เอเจนซี่

## ขั้นที่ 0: เช็คว่ามีบัญชีอยู่แล้วหรือยัง

ถามก่อนเสมอ: "มีบัญชี LINE Ads Manager อยู่แล้วไหม"

- **มีแล้ว** → ถามต่อว่าจะเปิดบัญชีใหม่สำหรับแบรนด์/ลูกค้าอื่น หรือใช้บัญชีเดิม ถ้าใช้บัญชีเดิม
  ข้ามไปขั้นวางแผนแคมเปญได้เลย
- **ไม่แน่ใจ** → แนะนำให้เจ้าของเข้าไปเช็คที่ `admanager.line.biz/adaccount/` ก่อนว่ามีชื่อ
  แบรนด์/บริษัทที่ต้องการอยู่แล้วหรือยัง

## ขั้นที่ 1: ตั้งบัญชี (ทำที่ LINE Ads Manager เท่านั้น)

ต้องรู้ก่อนเริ่มกรอกฟอร์ม:
- ขายอะไร (business type) เพราะกำหนดว่าต้องยื่นเอกสารเพิ่มหรือไม่ (ดู `line-ads-basics` เรื่องสินค้า
  ต้องห้าม/ต้องระวัง)
- สมัครในนามใคร (บุคคล/นิติบุคคล/เอเจนซี่แทนลูกค้า) เพราะฟิลด์ที่ต้องกรอกต่างกัน
- ข้อมูลที่เปลี่ยนทีหลังไม่ได้ ต้องทวนให้ชัดก่อน submit: หมวดหมู่ธุรกิจ, ประเทศ, timezone, สกุลเงิน

หลังได้บัญชีแล้ว เจ้าของจะมี Ad Account ID ซึ่งเป็นข้อมูลที่ต้องใช้ต่อในทุกขั้นถัดไป

## ขั้นที่ 2: วางแผนแคมเปญ (ถามตามลำดับ Campaign → Ad Set → Ad เท่านั้น)

**อย่าถามรายละเอียดระดับ Ad ก่อนที่ระดับ Campaign และ Ad Set จะชัดเจน**

ระดับ Campaign (ถามก่อน):
1. อยากให้แคมเปญนี้ทำอะไร (เพิ่มเพื่อน OA / เข้าเว็บ / ให้คนซื้อ) → ใช้เลือก objective ที่
   `line-ads-basics`
2. งบต่อวันหรืองบรวมทั้งแคมเปญเท่าไหร่
3. เริ่มยิงวันไหน

ระดับ Ad Set (ถามหลัง Campaign ชัดแล้ว):
1. หา Customer Avatar ก่อนเสมอ (Need → Ability → Life Stage ที่ `line-ads-targeting`)
   **ห้ามข้ามไปถามเรื่อง interest ตรงๆ**
2. อยากแบ่งกลุ่มเป้าหมายเป็นกี่กลุ่มเพื่อเทียบผลกัน
3. ถ้าจะตั้ง Cost Cap เอง สูงสุดกี่บาท (ดู `line-ads-bidding-budget`)

ระดับ Ad (ถามหลัง Ad Set ชัดแล้ว):
1. ครีเอทีฟที่มีอยู่ตรงกับสเปกไหม (ดู `line-ads-creative-specs`)
2. ข้อความ/ปุ่มกดตรงกับ objective ที่เลือกไหม

## ขั้นที่ 3: กติกาความปลอดภัยเรื่องเงินระหว่างวางแผน

- ห้ามเดางบรายวัน งบรวม หรือบิดแทนเจ้าของเด็ดขาด ต้องให้เจ้าของระบุตัวเลขเองทุกครั้ง
- ก่อนสรุปแผนให้เจ้าของไปสร้างจริง ต้องสรุปตัวเลข/เงื่อนไขทั้งหมดให้เจ้าของอ่านครบก่อน
- ถ้าเจ้าของเปลี่ยนจำนวน ad set/ad/ครีเอทีฟจากแผนเดิม ต้องทวนแผนใหม่กับเจ้าของอีกรอบก่อนไปต่อ

## ขั้นที่ 4: ส่งต่อให้เจ้าของลงมือทำจริง

สรุปแผนทั้งหมด (objective, งบ, กลุ่มเป้าหมาย, ครีเอทีฟที่ต้องเตรียม) เป็นเช็กลิสต์เดียว
แล้วบอกเจ้าของว่าขั้นตอนที่เหลือทั้งหมดต้องไปทำเองที่ `admanager.line.biz`

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามถามรายละเอียดระดับ Ad ก่อนที่ Campaign และ Ad Set จะชัดเจน
- ห้ามข้ามขั้น Customer Avatar ไปเลือก interest ตรงๆ
- ห้ามเดาตัวเลขงบ/บิด/วันที่แทนเจ้าของ
- ห้ามบอกว่าตั้งบัญชีหรือสร้างแคมเปญให้แล้ว ทุกขั้นตอนจริงเจ้าของต้องไปกดเองที่ LINE Ads Manager

## เกี่ยวข้อง

- วัตถุประสงค์และสินค้าต้องห้าม ดูที่ `line-ads-basics`
- วิธีคิด Customer Avatar และกลุ่มเป้าหมาย ดูที่ `line-ads-targeting`
- บิด/งบขั้นต่ำต่อ objective ดูที่ `line-ads-bidding-budget`
- สเปกครีเอทีฟที่ต้องเตรียม ดูที่ `line-ads-creative-specs`
- ตัวเลขอ้างอิงเทียบผลหลังแคมเปญรันแล้ว ดูที่ `line-ads-kpi-benchmark`
