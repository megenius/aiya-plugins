# line-ads-basics (ความรู้พื้นฐาน LINE Ads)

อ้างอิงจาก line-ads-mcp โดย Praphat Srisuma (Spark Factor) Apache-2.0

ตอบคำถามเดียว: **LINE Ads คืออะไร วัตถุประสงค์ไหนเหมาะกับร้านนี้ และร้านนี้ลงโฆษณาได้ไหม**

## ความจริงที่ต้องบอกเจ้าของร้านก่อนเสมอ (ห้ามข้าม)

- 🔴 **ระบบของ AIYA วันนี้ยังสร้าง/แก้/เปิดแคมเปญ LINE Ads แทนเจ้าของไม่ได้เลย** สกิลนี้ให้ความรู้และ
  เช็กลิสต์เท่านั้น การลงมือทำต้องไปที่ LINE Ads Manager (`admanager.line.biz`) ด้วยตัวเอง
- ตัวเลข/เกณฑ์ทั้งหมดในสกิลนี้มาจาก knowledge ของ line-ads-mcp บันทึกไว้ 2026-07 ไม่ใช่ตัวเลขสดจาก
  LINE API ห้ามพูดว่า "LINE บอกวันนี้ว่า" ให้พูดว่า "ตามข้อมูลอ้างอิงที่มี (2026-07)"

## เมื่อไหร่ใช้

- เจ้าของถามว่า "LINE Ads คืออะไร" หรือ "ต่างจากยิงแอด Facebook ยังไง"
- เจ้าของยังไม่รู้ว่าจะเลือกวัตถุประสงค์ไหน
- เจ้าของอยากรู้ว่าสินค้า/บริการของตัวเองลงโฆษณา LINE ได้ไหม

## วัตถุประสงค์ (Objective) 6 แบบ

| Objective | ใช้เมื่อ | Metric หลัก | Bid Type แนะนำ |
|---|---|---|---|
| GAIN_FRIENDS | อยากเพิ่มผู้ติดตาม LINE OA | Friend add (นับจาก Click) | CPF |
| WEBSITE_TRAFFIC | อยากพาคนเข้าเว็บ/หน้า Landing | Click, CTR, CPC | CPC |
| CONVERSIONS | อยากให้คนซื้อ/สมัคร/กรอกฟอร์มจริง | Conversion, CPA, CVR | CPC |
| REACH | อยากให้คนเห็นแบรนด์วงกว้าง | Reach, Frequency, CPM | CPM |
| APP_INSTALL | อยากให้คนโหลดแอป | Install, CPI | CPC |
| VIDEO_VIEW | อยากให้คนดูวิดีโอจบ | View, completion, CPV | CPV |

**ข้อสำคัญของ GAIN_FRIENDS**: โฆษณาชี้ไปหน้า Add Friend ของ LINE OA ตรงๆ ดังนั้น
**Click = การเพิ่มเพื่อนสำเร็จ** ไม่มี pixel event แยกต่างหาก และค่า `cv` (conversion) จะเป็น 0 เสมอ
นี่คือพฤติกรรมปกติของ objective นี้ ไม่ใช่ระบบพัง · ถ้าเจ้าของกังวลว่า "ทำไม conversion ขึ้น 0"
ให้อธิบายจุดนี้ก่อน อย่ารีบสรุปว่ามีปัญหา tracking

## สินค้า/บริการที่ห้ามหรือต้องระวัง (จากแนวทางของ LINE)

- ห้ามลงโฆษณาเด็ดขาด: บุหรี่/บุหรี่ไฟฟ้า, คริปโต (ยกเว้นสถาบันการเงินที่ได้รับอนุญาต), อาวุธ,
  ขายข้อมูลส่วนบุคคล, ธุรกิจแชร์ลูกโซ่/MLM ที่ไม่ได้รับอนุญาต, ซื้อขายสัตว์/อวัยวะสัตว์,
  ยาเสพติด, การพนันทุกประเภท, สินค้าผู้ใหญ่, นมผงสำหรับทารก, การตั้งครรภ์แทน/บุตรบุญธรรม,
  เว็บสะสมแต้มที่เข้าข่ายพนัน, การกู้ยืมเชิงฉ้อโกง, สินค้าละเมิดลิขสิทธิ์, การตลาดออนไลน์แบ่งปันรายได้,
  NGO ที่ไม่ได้รับอนุญาต
- ต้องยื่นเอกสารเพิ่มก่อนลงได้: อาหาร/เครื่องดื่มบรรจุภัณฑ์ (ใบอนุญาต อย.), อาหารเสริม/วิตามิน
  (เลขทะเบียน อย. ต่อ SKU ห้ามอ้างสรรพคุณรักษาโรค), เครื่องสำอาง/สกินแคร์ (ใบจดแจ้ง อย.
  ห้ามอ้างเกินจริงเช่น whitening/anti-aging รุนแรง), ตัวแทนขายสินค้า (หนังสือแต่งตั้งจากบริษัทแม่),
  มูลนิธิ/NGO (หนังสือจดทะเบียนจากกรมการปกครอง)
- รายการนี้สรุปจากข้อมูลอ้างอิงเดียวกัน ไม่ใช่กฎหมายฉบับล่าสุดของ LINE เสมอไป **ถ้าสินค้าอยู่กลุ่ม
  สีเทาหรือควบคุม ให้บอกเจ้าของให้ไปเช็คกติกาจริงที่ LINE Ads Manager ก่อนวางแผนใดๆ**

## ขั้นตอน

1. ถามเจ้าของว่า "อยากให้แคมเปญนี้ทำอะไร" แล้วจับคู่กับตารางวัตถุประสงค์ด้านบน
2. เช็คว่าสินค้า/บริการอยู่ในรายการห้าม/ต้องระวังไหม ถ้าใช่ บอกตรงๆ ก่อนคุยเรื่องอื่นต่อ
3. ถ้าเลือกวัตถุประสงค์ได้แล้ว ส่งต่อบิด/งบไปที่ `line-ads-bidding-budget`
   และสเปกครีเอทีฟไปที่ `line-ads-creative-specs`
4. ย้ำเสมอว่าขั้นสร้างจริงต้องไปทำที่ LINE Ads Manager เอง

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามบอกว่าระบบ AIYA "สร้างแคมเปญ LINE Ads ให้แล้ว" เพราะไม่มีเครื่องมือแบบนั้นอยู่จริงวันนี้
- ห้ามพูดแทน LINE ว่าสินค้าที่อยู่กลุ่มควบคุมจะผ่านหรือไม่ผ่านแน่นอน ให้บอกว่าต้องยื่นเอกสารและ
  ให้ LINE ตรวจเอง
- ห้ามยกตัวเลข CPF/CPC/CPM จากความจำ ให้ส่งต่อไปที่ `line-ads-kpi-benchmark`

## เกี่ยวข้อง

- ตัวเลขอ้างอิงต้นทุน/CTR ดูที่ `line-ads-kpi-benchmark`
- เลือกกลุ่มเป้าหมายดูที่ `line-ads-targeting`
- บิด/งบขั้นต่ำต่อ objective ดูที่ `line-ads-bidding-budget`
- ขนาดรูป/วิดีโอที่ต้องใช้ ดูที่ `line-ads-creative-specs`
- ลำดับคำถามเต็มตั้งแต่ตั้งบัญชีถึงสร้างแคมเปญ ดูที่ `line-ads-campaign-workflow`
- ยิงแอด Meta/Facebook ที่ระบบทำได้จริงวันนี้ ดูที่ `safe-ads`
