# line-ads-creative-specs (ขนาดและสเปกครีเอทีฟ LINE Ads)

อ้างอิงจาก line-ads-mcp โดย Praphat Srisuma (Spark Factor) Apache-2.0

ตอบคำถามเดียว: **รูปหรือวิดีโอที่จะใช้ยิงแอด LINE ต้องมีขนาด/สัดส่วน/ขนาดไฟล์เท่าไหร่ถึงจะอัปโหลดผ่าน**

## ความจริงที่ต้องบอกเจ้าของร้านก่อนเสมอ (ห้ามข้าม)

- 🔴 **ระบบ AIYA ยังอัปโหลดครีเอทีฟเข้า LINE Ads Manager แทนเจ้าของไม่ได้** สกิลนี้บอกแค่สเปกที่
  ต้องเตรียมไว้ล่วงหน้า การอัปโหลดจริงต้องทำที่หน้า LINE Ads Manager เอง
- สเปกด้านล่างเป็นข้อมูลอ้างอิงจาก line-ads-mcp บันทึก 2026-07 ถ้าอัปโหลดแล้วระบบ LINE ฟ้อง error
  ที่ไม่ตรงกับตารางนี้ ให้เชื่อหน้าจอจริงมากกว่าตารางนี้เสมอ (สเปกแพลตฟอร์มเปลี่ยนได้)

## เมื่อไหร่ใช้

- เจ้าของกำลังจะส่งรูป/วิดีโอให้ทีมออกแบบทำสำหรับแคมเปญ LINE Ads
- เจ้าของถามว่าทำไมอัปโหลดรูปแล้วขึ้น error
- ต้องเลือกฟอร์แมตครีเอทีฟให้ตรงกับวัตถุประสงค์แคมเปญ

## ฟอร์แมตที่แนะนำต่อวัตถุประสงค์

| Objective | ฟอร์แมตแนะนำ | หมายเหตุ |
|---|---|---|
| GAIN_FRIENDS | รูปสี่เหลี่ยมจัตุรัส 1:1 | เด่นใน feed เหมาะกับปุ่มเพิ่มเพื่อน |
| WEBSITE_TRAFFIC | รูป 1.91:1 หรือ Carousel | Carousel เหมาะเมื่อมีหลาย pain point/โปรโมชัน |
| CONVERSIONS | รูป 1:1 หรือ Carousel | ใช้ฟอร์แมตที่เห็นข้อเสนอ/หลักฐานชัด |
| REACH | รูป 1.91:1 | เหมาะกับข้อความกว้างๆ เน้นการมองเห็น |
| APP_INSTALL | รูป 1:1 หรือวิดีโอ 1:1 | โชว์หน้าจอแอปหรือการใช้งานสั้นๆ |
| VIDEO_VIEW | วิดีโอ 1:1 หรือ 16:9 | แนะนำ 15-30 วินาทีสำหรับ performance |

## สเปกตามชนิดครีเอทีฟ

**รูปภาพ (Image Ad)**
- ไฟล์: JPG, PNG · ขนาดไฟล์ไม่เกิน 10MB ต่อภาพ
- สัดส่วน: 1.91:1 (1200×628px) หรือ 1:1 (1080×1080px)
- ข้อความในรูปไม่เกิน 20% ของพื้นที่ภาพ

**รูปเล็ก (Small Image Ad)**
- ไฟล์: JPG, PNG · ขนาดไฟล์ไม่เกิน 10MB · ขนาดแนะนำ 600×400px

**วิดีโอ (Video Ad)**
- ไฟล์: MP4, MOV · ขนาดไฟล์ไม่เกิน 1GB · ความยาวไม่เกิน 600 วินาที (แนะนำ 15-30 วินาทีสำหรับ performance)
- สัดส่วน/ความละเอียด: 1:1 (600-1280px ต่อด้าน) · 16:9 (240-1920 × 135-1080px) · 9:16 (135-1080 × 240-1920px)

**วิดีโอเล็ก (Small Video Ad)**
- ไฟล์: MP4, MOV · ขนาดไฟล์ไม่เกิน 1GB · ความยาวไม่เกิน 600 วินาที
- สัดส่วน: 1:1 (600-1280px ต่อด้าน) หรือ 16:9 (240-1920 × 135-1080px)

**Carousel Ad**
- จำนวนภาพ: 2-10 ภาพ (สูงสุด 10 การ์ด) · แต่ละภาพสัดส่วน 1:1 (1080×1080px)
- ไฟล์: JPG, PNG · ขนาดไฟล์ไม่เกิน 10MB ต่อภาพ

**Animation Ad**
- ไฟล์: PNG แบบ APNG · ขนาดไฟล์ไม่เกิน 300KB ต่อภาพเคลื่อนไหว · ขนาดภาพ 600×400px
- ความยาว 1-4 วินาที · เฟรม 5-20 · วนซ้ำได้ 1-4 รอบ

## Error ที่พบบ่อยและวิธีแก้

| Error | สาเหตุ | วิธีแก้ |
|---|---|---|
| File too large | รูปเกิน 10MB หรือวิดีโอเกิน 1GB | บีบอัดไฟล์หรือลดความละเอียด |
| Wrong aspect ratio | สัดส่วนไม่ตรงสเปก | ครอปให้ได้ 1.91:1 หรือ 1:1 ตามชนิด |
| Too much text | ข้อความในรูปเกิน 20% ของพื้นที่ | ลดข้อความในรูป ย้ายข้อความไป caption แทน |
| Unsupported format | ไฟล์ไม่ใช่ JPG/PNG/MP4/MOV | แปลงไฟล์ก่อนอัปโหลด |

## ขั้นตอน

1. ถามเจ้าของว่าวัตถุประสงค์ของแคมเปญคืออะไร แล้วแนะนำฟอร์แมตจากตารางแรก
2. ส่งสเปกที่ตรงกับชนิดครีเอทีฟให้ทีมออกแบบเตรียมไฟล์ล่วงหน้า
3. เตือนเรื่องข้อความในรูปไม่เกิน 20% ทุกครั้งที่มีรูปโปรโมชันแปะตัวเลข/ราคา
4. ถ้าเจ้าของแจ้งว่าอัปโหลดไม่ผ่าน ให้เทียบ error กับตาราง Error ด้านบนก่อนเดาสาเหตุอื่น

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามยืนยันว่าสเปกในสกิลนี้เป็นค่าล่าสุดแน่นอน ถ้าเจ้าของเจอ error ที่ไม่ตรงกับตารางนี้ ให้เชื่อ
  ข้อความจริงบนหน้าจอ LINE Ads Manager มากกว่า
- ห้ามอัปโหลดหรือส่งไฟล์แทนเจ้าของ สกิลนี้ให้ความรู้เท่านั้น

## เกี่ยวข้อง

- วัตถุประสงค์แคมเปญที่กำหนดว่าเลือกฟอร์แมตไหน ดูที่ `line-ads-basics`
- ขั้นตอนเต็มตั้งแต่ตั้งบัญชีถึงสร้างแคมเปญ ดูที่ `line-ads-campaign-workflow`
- ทำครีเอทีฟฝั่ง Meta/Instagram/TikTok ที่ระบบมีเครื่องมือช่วยจริง ดูที่ `video-brief`, `infographic-brief`, `motion-brief`
