# คู่มือ TikTok (อ่านสดทุกครั้ง)

ใช้เมื่อจะวางแผนคลิป TikTok ขายของบน TikTok Shop หรือยิงแอด TikTok
ไฟล์นี้เก็บ **วิธีคิดกับลำดับตรวจ** เท่านั้น ตัวเลขค่าธรรมเนียม สเปก และกติกาอยู่ในคู่มือที่ต้องอ่านสด

## เมื่อไหร่ใช้

- ก่อนบรีฟคลิปสั้นหรือไลฟ์ขายของ
- ก่อนตอบว่า "ขายบน TikTok Shop คุ้มไหม" หรือ "ยิงแอดแบบไหนดี"
- ก่อนพูดว่า "For You เลือกจากอะไร"

## ลำดับตรวจ (ห้ามสลับ)

1. **เรียก `mkt_playbook_list` ด้วย platform เป็น tiktok ก่อนตอบ**
2. **อ่านทั้งรายการที่ใช้ได้และรายการที่หมดอายุ**
3. **กรองชนิดให้ตรงคำถาม**
   - ถามว่าคลิปจะถูกดันไหม ใช้ชนิด algorithm
   - ถามสเปกคลิปหรือฮุก ใช้ชนิด creative_spec
   - ถามระบบยิงแอดหรือเครื่องมือของร้านค้า ใช้ชนิด ads_product
   - ถามค่าธรรมเนียมหรือเกณฑ์ ใช้ชนิด benchmark
   - ถามการเชื่อมระบบหรือโพสต์อัตโนมัติ ใช้ชนิด api_version
4. **แยกให้ชัดว่าข้อไหนเป็นของทางการ ข้อไหนเป็นของคนทำงานเล่าต่อ** คู่มือบอกที่มาไว้แล้ว ให้ยกป้ายนั้นมาด้วยทุกครั้ง
5. **จบด้วยหนึ่งการกระทำที่ทำได้สัปดาห์นี้**

## กติกาคู่มือหมดอายุ

- ข้อที่หมดอายุ ห้ามใช้ตอบเหมือนยังใช้ได้ ห้ามเดาแทน ให้พูดว่า "คู่มือหมดอายุ"
- ตรวจทั้งชุดด้วย `mkt_playbook_expire_check`
- ไม่มีคู่มือสด ยังทำงานส่วนที่เหลือต่อได้ แค่ติดป้ายว่าข้อไหนยังไม่ยืนยัน
- เรื่องค่าธรรมเนียมและกติกาการขาย ถ้าคู่มือหมดอายุให้บอกเจ้าของว่าต้องเช็คจากหน้าทางการก่อนตัดสินใจเรื่องเงิน

## คำถามที่ต้องถามก่อนบรีฟ

1. ร้านขายผ่าน TikTok Shop จริงหรือใช้ TikTok พาคนไปคุยที่ช่องทางอื่น
2. ใครถ่ายและตัดคลิป และทำได้กี่คลิปต่อสัปดาห์
3. สินค้ามีข้อจำกัดเรื่องคำกล่าวอ้างไหม เช่น เรื่องสุขภาพหรือผลลัพธ์
4. มีคลิปเก่าที่ทำผลดีอยู่แล้วไหม (ต่อยอดของที่วิ่งอยู่ถูกกว่าเริ่มใหม่)

## ข้อห้าม

- ห้ามพิมพ์ตัวเลขค่าธรรมเนียม เกณฑ์ หรือเวอร์ชันจากความจำ ต้องยกจากคู่มือที่เพิ่งอ่าน
- ห้ามโพสต์เอง ห้ามเปิดแอดเอง ห้ามใช้เงิน ทีมนี้เป็นระดับอำนาจ 2
- ห้ามเอาตัวเลขระดับแพลตฟอร์มมาพูดแทนผลของร้าน ผลของร้านมาจาก `mkt_listen_run`

- ยิงแอดแบบปลอดภัยที่ `safe-ads`
