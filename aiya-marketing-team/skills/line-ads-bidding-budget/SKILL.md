# line-ads-bidding-budget (บิดและงบขั้นต่ำ LINE Ads)

อ้างอิงจาก line-ads-mcp โดย Praphat Srisuma (Spark Factor) Apache-2.0

ตอบคำถามเดียว: **แคมเปญนี้ควรตั้งบิดแบบไหน งบต่อวันเท่าไหร่ และตอนไหนถึงควรสลับจาก Auto ไป Manual**

## ความจริงที่ต้องบอกเจ้าของร้านก่อนเสมอ (ห้ามข้าม)

- 🔴 **สกิลนี้ไม่ตัดสินใจตัวเลขเงินแทนเจ้าของ** เสนอได้แค่ช่วงอ้างอิงจากข้อมูล line-ads-mcp
  (บันทึก 2026-07) เจ้าของต้องเป็นคนระบุงบ/บิดสุดท้ายเอง
- 🔴 **ระบบ AIYA ยังตั้งบิด/งบ หรือสร้างแคมเปญ LINE Ads แทนเจ้าของไม่ได้เลย** การตั้งค่าจริงต้องไปทำ
  ที่ LINE Ads Manager

## เมื่อไหร่ใช้

- เจ้าของถามว่า "งบต่อวันควรตั้งเท่าไหร่"
- เจ้าของถามว่าจะสลับจาก bidding อัตโนมัติเป็นตั้งเองดีไหม
- แคมเปญใช้งบไม่หมดตามที่ตั้งไว้ (underspend)

## Bid Type และงบขั้นต่ำต่อ Objective

| Objective | Bid Type | กลยุทธ์แนะนำ | งบขั้นต่ำ/วัน (อ้างอิง) |
|---|---|---|---|
| GAIN_FRIENDS | CPF | Cost Cap หรือ Lowest Cost | ฿100 |
| WEBSITE_TRAFFIC | CPC | Cost Cap หรือ Lowest Cost | ฿100 |
| CONVERSIONS | CPC | Cost Cap | ฿300 |
| REACH | CPM | Lowest Cost | ฿50 |
| APP_INSTALL | CPC | Cost Cap หรือ Lowest Cost | ฿100 |
| VIDEO_VIEW | CPV | Lowest Cost | ฿50 |

## ต้นทุนอ้างอิงช่วงกลาง (ตัวเลขจริงจาก LINE Ads ไทย ผ่าน snapshot ของ line-ads-mcp)

| Objective | ต้นทุนปกติ |
|---|---|
| GAIN_FRIENDS | CPF ฿10-22 (ขึ้นกับอุตสาหกรรม) |
| WEBSITE_TRAFFIC | CPC ฿1.70-3.50 |
| REACH | CPM ฿6-8 |
| VIDEO_VIEW | CPV ฿0.02-0.09 |
| APP_INSTALL | CPC ฿0.90-3.70 |
| WEBSITE_CONVERSION | CPC ฿1.90-3.40 |

หมายเหตุ: GAIN_FRIENDS มี CPF สูงสุดในกลุ่มธุรกิจสุขภาพ/ฟิตเนส และต่ำสุดในกลุ่มกฎหมาย/ราชการ
ตามข้อมูลอ้างอิงเดียวกัน (ดูตารางเต็มแยกอุตสาหกรรมที่ `line-ads-kpi-benchmark`)

## Learning Phase (ช่วงเรียนรู้ของระบบ)

- ช่วงเรียนรู้ยาว 7-14 วันแรกหลังเปิดแคมเปญหรือแก้ targeting/bidding ครั้งใหญ่
- ระหว่างช่วงนี้: ห้ามเปลี่ยน targeting/bidding บ่อย, ห้ามเพิ่มงบเกิน 20% ต่อวัน, ผลลัพธ์ผันผวนถือว่าปกติ
- สถานะ "กำลังเรียนรู้" ที่ขึ้นในระบบ LINE Ads ให้รอครบ 14 วันก่อนตัดสินว่าแคมเปญดีหรือแย่

## เมื่อไหร่ควรสลับจาก Auto เป็น Manual Bid

ใช้ Auto ก่อนเสมอในช่วง 2-3 วันแรก แล้วพิจารณาสลับเป็น Manual เมื่อเข้าเงื่อนไขข้อใดข้อหนึ่ง:

- ใช้งบไม่ถึง 60% ของงบต่อวันติดต่อกัน 3 วัน (underspend)
- CPF/CPC/CPA สูงกว่า benchmark ระดับสูงสุดของอุตสาหกรรมติดต่อกันมากกว่า 2 วัน
- Learning phase จบแล้ว (เกิน 14 วัน) แต่ผลลัพธ์ยังไม่ดีเทียบกับ benchmark
- เจ้าของต้องการควบคุมเพดานราคาชัดเจนด้วยตัวเอง

ก่อนสลับ: เทียบตัวเลขกับ `line-ads-kpi-benchmark` ก่อนเสมอ **ห้ามเลือกตัวเลข manual bid แทนเจ้าของ**
ให้เสนอช่วงอ้างอิงแล้วถามให้เจ้าของระบุตัวเลขเอง ถ้าแคมเปญอายุน้อยกว่า 3 วัน ให้ระวังการสรุปเพราะยัง
อยู่ช่วง early delivery

## ขั้นตอน

1. ถามวัตถุประสงค์แคมเปญก่อน (ดู `line-ads-basics`) แล้วจับคู่ bid type/งบขั้นต่ำจากตารางแรก
2. ถามเจ้าของว่างบต่อวันที่รับได้คือเท่าไหร่ (ต้องไม่ต่ำกว่างบขั้นต่ำของ objective นั้น)
3. ถ้าแคมเปญรันมาแล้ว เช็คว่าอยู่ใน Learning Phase หรือยัง ก่อนแนะนำให้ปรับอะไร
4. ถ้าเข้าเงื่อนไขสลับ Manual ให้เสนอช่วงอ้างอิงแล้วให้เจ้าของตัดสินตัวเลขสุดท้ายเอง
5. ย้ำว่าการตั้งค่าจริงต้องไปทำที่ LINE Ads Manager

## กฎก่อนสรุป (ห้ามฝ่าฝืน)

- ห้ามเลือกตัวเลขงบหรือบิดสุดท้ายแทนเจ้าของ เสนอได้แค่ช่วงอ้างอิง
- ห้ามแนะนำให้ปรับ targeting/bidding ระหว่าง Learning Phase (7-14 วันแรก) เว้นแต่เจ้าของยืนยันว่า
  รับความเสี่ยงที่ระบบจะเริ่มเรียนรู้ใหม่
- ห้ามเสนอเพิ่มงบเกิน 20% ต่อวันในช่วง Learning Phase
- ห้ามพูดว่าระบบ AIYA ตั้งค่าบิด/งบให้แล้ว เพราะไม่มีเครื่องมือทำแบบนั้นอยู่จริงวันนี้

## เกี่ยวข้อง

- ตัวเลข CTR/ต้นทุนแยกอุตสาหกรรมแบบละเอียด ดูที่ `line-ads-kpi-benchmark`
- วัตถุประสงค์ที่กำหนด bid type ดูที่ `line-ads-basics`
- เพดานงบและขั้นเตรียม-ยืนยัน-ยิงจริงของฝั่ง Meta ที่ระบบทำได้วันนี้ ดูที่ `safe-ads`, `ad-bid-guardrails`
