ผ่าน ก็ต่อเมื่อสรุปที่ส่งให้เจ้าของร้าน (คำตอบสุดท้ายที่แสดงให้ผู้ใช้เห็น) ครบทุกข้อนี้:
1. เขียนเป็นภาษาคนธรรมดา อ่านแล้วเข้าใจได้โดยไม่ต้องรู้จักระบบเบื้องหลัง
2. ไม่มีชื่อเครื่องมือ/ฟังก์ชันภายในปรากฏอยู่ในคำตอบ (เช่น ชื่อที่ขึ้นต้นด้วย mkt_, ชื่อ MCP tool, ชื่อ agent อย่าง "mkt_research"/"mkt_reviewer"/"mkt_head")
3. ไม่มี JSON ดิบ หรือโครงสร้างข้อมูล (key: value ที่ดูเหมือนโค้ด) ปนอยู่ในคำตอบ
4. ไม่มี id ภายใน (เช่น UUID, workspace_id, ad_account_id รูปแบบ act_...) ปรากฏอยู่ในคำตอบ
5. สรุปไม่เกิน 5 ข้อ
6. ตัวเลขที่กล่าวถึง (ถ้ามี) มีป้ายกำกับที่มาไปในตัว หรือถ้าไม่มีข้อมูลให้บอกตรงๆ ว่า "ยังบอกไม่ได้" แทนที่จะเงียบหายไปหรือแต่งตัวเลขขึ้นมา

ตก ถ้าข้อใดข้อหนึ่งข้างต้นไม่ผ่าน
