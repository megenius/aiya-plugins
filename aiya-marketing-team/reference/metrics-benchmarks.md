# นิยามตัวชี้วัดของทีมการตลาด

ทุกตัวเลขในรายงานต้องใช้นิยามเดียวกันกับไฟล์นี้ ถ้าคนละนิยามกับที่นี่ ต้องบอกก่อนว่าใช้นิยามอะไร
ห้ามใส่ตัวเลข benchmark เปรียบเทียบที่ไม่มีที่มา ให้เทียบกับตัวเองช่วงก่อนหน้าเป็นหลัก

## ตัวชี้วัดหลัก

### reach (การเข้าถึง)
จำนวนคนที่เห็นเนื้อหาอย่างน้อย 1 ครั้งในช่วงเวลาที่รายงาน
- มาจาก: รายงานของแพลตฟอร์ม (เพจ/LINE/แอด) ผ่าน connector
- ระวัง: reach ไม่ใช่ยอดผู้ติดตาม และไม่ใช่ impression (จำนวนครั้งที่แสดง)

### CTR (click-through rate)
จำนวนคลิกหารด้วยจำนวนครั้งที่แสดง (impression) ในช่วงเวลาเดียวกัน คูณ 100
- CTR = (clicks / impressions) x 100
- ต้องระบุที่มาของ clicks และ impressions ให้ชัดว่านับตรงไหน (ปุ่มไหน แคมเปญไหน)

### cost per message (ต้นทุนต่อข้อความทัก)
เงินที่ใช้ไปกับแคมเปญ หารด้วยจำนวนข้อความ/ห้องแชทใหม่ที่เข้ามาจากแคมเปญนั้น
- cost per message = spend / new chats attributed
- ถ้าแยกว่าข้อความไหนมาจากแคมเปญไหนไม่ได้ ให้บอกว่าเป็นการกระจายทั้งก้อน ห้ามอ้างเป๊ะ

## ฟันเนล 4 ขั้น

1. **เข้าถึง (reach)** คนเห็นเรา
2. **สนใจ (engage)** คนคลิก/ทักเข้ามา (ใช้ CTR และจำนวนข้อความใหม่)
3. **คุย (chat)** ห้องแชทที่ตอบกลับไปแล้ว (ไม่ใช่แค่ทัก ต้องมีการตอบของเราด้วย)
4. **ปิด (close)** ออเดอร์/ยอดซื้อที่บันทึกได้จริงในระบบ

อ่านจากบนลงล่าง แต่ตัดสินใจจาก "ขั้นที่ตกมากที่สุดเทียบกับขั้นก่อนหน้า" ไม่ใช่ขั้นที่ตัวเลขเล็กสุด
ทุกขั้นต้องติดป้ายว่า วัดจากระบบ / เจ้าของประเมิน / ยังไม่รู้ (ใช้แนวทางเดียวกับ skill `leak`)

## กติกาการอ่านและรายงาน

- เทียบกับตัวเอง: สัปดาห์นี้ vs สัปดาห์ก่อน เดือนนี้ vs เดือนก่อน เท่านั้น
- ห้ามเดาตัวเลขที่ระบบไม่มี ให้เขียน "ยังไม่รู้" พร้อมบอกว่าต้องเก็บข้อมูลอะไรเพิ่ม
- จำนวนนับน้อย (เช่น ข้อความใหม่ 3 ข้อความ) ห้ามคิดเป็นเปอร์เซ็นต์ ให้รายงานเป็นจำนวนเป๊ะ
- benchmark จากภายนอกใช้ได้เฉพาะเมื่อระบุที่มาชัดเจน ไม่มีที่มา = ไม่ใส่
