# การเชื่อมต่อเพจ / LINE / แอด ทีละขั้น

ทำตามลำดับ ห้ามข้ามขั้น ถ้าขั้นไหนติดให้หยุดและบอกสิ่งที่เห็นตรงๆ ห้ามทำต่อโดยเดาว่าผ่านแล้ว

## ตารางแปลชื่อระบบ (ที่เดียวที่มีตารางนี้ command/agent อื่นให้อ้างมาที่นี่)

เวลาบอกเจ้าของร้านว่าต้องเชื่อมต่ออะไร ให้ใช้คอลัมน์ซ้ายเท่านั้น **ห้ามพูดชื่อ connector, ชื่อ tool, หรือชื่อ agent ภายในกับเจ้าของร้านเด็ดขาด** (ชื่อพวกนี้มีไว้คุยกันในทีมพัฒนาเท่านั้น)

| บอกเจ้าของร้านว่า | connector ภายใน (ห้ามพูดชื่อนี้) | เชื่อมต่อยังไง (บอกเจ้าของร้านแบบนี้) |
|---|---|---|
| เพจ Facebook/Instagram | `aiya-page` | เปิดเมนูเชื่อมต่อเครื่องมือ (`/mcp`) แล้วกด login ด้วยบัญชี Facebook ที่เป็นแอดมินเพจร้าน |
| LINE Official Account (LINE OA) | `aiya-line` | เปิดเมนูเชื่อมต่อเครื่องมือ (`/mcp`) แล้วกด login ด้วยบัญชีแอดมิน LINE OA ของร้าน |
| บัญชีโฆษณา | `aiya-ads` | เปิดเมนูเชื่อมต่อเครื่องมือ (`/mcp`) แล้วกด login ด้วยบัญชีที่มีสิทธิ์ใน Business Manager/ad account ของร้าน (ต้องต่อเพจก่อน) |
| ระบบขาย/ออเดอร์ | `aiya-sales` | เปิดเมนูเชื่อมต่อเครื่องมือ (`/mcp`) แล้วกด login ด้วยบัญชีแอดมินระบบขายของร้าน |
| ระบบอีเวนต์/กิจกรรมร้าน | `aiya-events` | เปิดเมนูเชื่อมต่อเครื่องมือ (`/mcp`) แล้วกด login ด้วยบัญชีแอดมินระบบอีเวนต์ของร้าน |

ตัวอย่างประโยคที่ถูก (ภาษาคน ไม่เอ่ยชื่อระบบภายใน):
> "ยังเชื่อมต่อ LINE Official Account ของร้านไม่ได้ เปิดเมนูเชื่อมต่อเครื่องมือแล้วกด login ด้วยบัญชีแอดมิน LINE OA ก่อน ถึงจะดึงตัวเลขให้ได้ครับ"

ตัวอย่างประโยคที่ผิด (หลุดชื่อระบบภายใน ห้ามพูดแบบนี้):
> "เรียก aiya-line ไม่ติดเพราะ connector ยังไม่ login และ analyst เรียก mkt_outcome_list ไม่สำเร็จ"

## 0. ติดตั้งและล็อกอิน connector (ครั้งแรกเท่านั้น)

1. ติดตั้งปลั๊กอิน `aiya-marketing-team` (ดูวิธีใน README)
2. เปิด `/mcp` จะเห็น connector 5 ตัว: `aiya-page` `aiya-ads` `aiya-line` `aiya-sales` `aiya-events`
3. ทุกตัวเป็นแบบ HTTP + OAuth ถ้ายังไม่ล็อกอินจะขึ้น 401 ให้กด login ทีละตัวด้วยบัญชี AIYA ของร้าน
4. สถานะ connected = ใช้ได้ ถ้าหมดอายุภายหลัง ให้ login ใหม่ด้วยขั้นตอนเดียวกัน

## 1. ต่อเพจ (aiya-page)

1. ให้เจ้าของร้านล็อกอินด้วยบัญชี Facebook ที่เป็นแอดมินของเพจ
2. ยืนยันสิทธิ์ (permission) ที่ระบบขอ อ่านทุกข้อก่อนกดยอมรับ
3. เลือกเพจที่จะต่อ (กรณีมีหลายเพจ เลือกเฉพาะเพจของร้าน)
4. ทดสอบ: ให้ agent `page-admin` ดึงข้อมูลเพจ ถ้าได้ชื่อเพจและข้อมูลล่าสุด = ผ่าน

## 2. ต่อ LINE Official Account (aiya-line)

1. เตรียมสิทธิ์แอดมินของ LINE OA ของร้าน (ผู้ดูแลหลักหรือผู้ดูแลที่มีสิทธิ์ตั้งค่า)
2. ล็อกอินและยืนยันสิทธิ์ตามหน้าจอ LINE
3. เลือก OA ที่จะต่อ ถ้าร้านมีหลายช่องทาง ให้เจ้าของร้านเลือก
4. ทดสอบ: ดึงจำนวนผู้ติดตามหรือสถิติข้อความล่าสุดจาก connector

## 3. ต่อบัญชีโฆษณา (aiya-ads)

1. ต้องต่อเพจ (ขั้น 1) สำเร็จก่อน เพราะแคมเปญผูกกับเพจ
2. ล็อกอินด้วยบัญชีที่มีสิทธิ์ใน Business Manager / ad account ของร้าน
3. ยืนยันสิทธิ์แบบอ่าน (read) ก่อน ห้ามขอสิทธิ์ใช้จ่ายเกินจำเป็น
4. ทดสอบ: ดึงรายการแคมเปญเดิมกับงบที่ใช้ไป (อ่านอย่างเดียว ยังไม่สั่งอะไร)
5. 🔴 การสร้างแคมเปญใหม่หรือปรับงบต้องเป็นร่าง + เจ้าของร้านกดยืนยันเสมอ
