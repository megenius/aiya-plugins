สถานที่/พิกัด/จังหวัดที่ผู้ใช้ระบุ: $ARGUMENTS

ทำตามสกิล `flood-answer` ของปลั๊กอินนี้ทุกข้อ:

1. ถ้า $ARGUMENTS ว่างเปล่า ให้ถามผู้ใช้ว่าจะดูที่ไหน (ชื่อสถานที่/เขต/อำเภอ/จังหวัด หรือพิกัด)
2. เลือกเครื่องมือ MCP `nam-aiya` ให้ตรงกับคำถาม (ที่อยู่ กทม. → `geocode_place`→`place_summary` · คลอง กทม. → `bkk_canals` · ต่างจังหวัด → `search_stations`/`stations_near`)
3. ตรวจกับกับดักใน `flood-data-caveats` ก่อนแปลตัวเลข (min_bank=0, margin=0, faulty, เกณฑ์วิกฤต สนน.)
4. ตอบตามรูปแบบใน `flood-answer` §3 — มีเวลาที่วัด แหล่งข้อมูล และปิดท้ายด้วย ปภ. 1784 เสมอ
5. ห้ามพยากรณ์ ห้ามคำว่า ปลอดภัย/ไม่ปลอดภัย/ควรอพยพ/ยังไม่ต้องห่วง

## เครื่องมือ MCP ที่คำสั่งนี้ใช้

- `geocode_place`
- `place_summary`
- `bkk_canals`
- `search_stations`
- `stations_near`
- `station_detail`
- `water_status`
