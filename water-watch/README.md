# น้ำ.aiya.ai — ปลั๊กอินสำหรับ Claude Code / Cowork

ปลั๊กอินนี้คือ **คู่มือกำกับการตอบคำถามน้ำท่วม/ระดับน้ำ** โดยใช้ข้อมูลที่วัดได้จริงจาก
MCP สาธารณะ `nam-aiya` (`https://xn--q3c4c8cq.aiya.ai/mcp`) เท่านั้น — **อ่านอย่างเดียว ไม่ต้องล็อกอิน**
ไม่มีการพยากรณ์ ไม่มีการตัดสินใจแทนผู้ใช้ ทุกคำตอบมีเวลาที่วัดจริงกำกับ

---

## ⚠️ กฎความปลอดภัยของข้อมูล (สำคัญที่สุด)

งานนี้ต่างจากปลั๊กอินอื่น — **ถ้าข้อมูลผิดหรือสื่อสารผิด คนอาจบาดเจ็บหรือเสียชีวิต**

1. **ห้ามพยากรณ์** ทุกตัวเลขต้องเป็นค่าที่วัดได้จริงเท่านั้น
2. **ห้ามตัดสินใจแทนผู้ใช้** ห้ามคำว่า ปลอดภัย / ไม่ปลอดภัย / ควรอพยพ / ยังไม่ต้องห่วง
3. **ทุกคำตอบต้องมีเวลาที่วัด** และเตือนเมื่อข้อมูลเก่ากว่า 1 ชั่วโมง
4. **ทุกคำตอบต้องมีสายด่วน ปภ. 1784** และเครดิตหน่วยงานเจ้าของข้อมูล
5. **API ล่ม = ต้องบอกว่าล่ม** ห้ามแสดงค่าเก่าเงียบๆ
6. **ห้ามเก็บพิกัดผู้ใช้ลงฐาน** — ปลั๊กอินนี้ไม่มีเครื่องมือเขียนใดๆ อยู่แล้ว (อ่านอย่างเดียวทั้งหมด)

กฎเต็มอยู่ที่ [`CLAUDE.md`](../../CLAUDE.md) และ [`HANDOFF.md`](../../HANDOFF.md) ของ repo `water-watch`

## ติดตั้ง

### Claude Code (CLI)

จาก repo นี้ (โฟลเดอร์ ไม่ใช่ลิงก์ออนไลน์):

```bash
/plugin marketplace add ./plugin
/plugin install water-watch@water-watch
```

(ชื่อ marketplace มาจาก `plugin/.claude-plugin/marketplace.json` — ถ้าเปลี่ยนชื่อในอนาคตให้เช็คไฟล์นั้นก่อนสั่งติดตั้ง)

ถ้าจะแชร์เป็น repo ออนไลน์ภายหลัง ใช้รูปแบบเดียวกับ marketplace อื่นของ AIYA:
```bash
/plugin marketplace add <org>/<repo>
/plugin install water-watch@water-watch
```

### Claude Cowork

1. เปิดหน้าตั้งค่า Plugin ของ Cowork
2. เพิ่ม marketplace จากโฟลเดอร์ `plugin/` ของ repo นี้ (หรือลิงก์ repo ถ้าเผยแพร่แล้ว)
3. ติดตั้งปลั๊กอิน `water-watch`

ไม่ต้องล็อกอิน/ไม่ต้อง OAuth ใดๆ — MCP `nam-aiya` เป็นสาธารณะและอ่านอย่างเดียว

### ลองใช้

```
/น้ำ อนุสาวรีย์ชัยสมรภูมิ
/สถานการณ์ ราชเทวี
```

หรือคุยเป็นภาษาคนได้เลย เช่น "แถวบ้านฉันน้ำท่วมไหม" "คลองแสนแสบล้นหรือยัง" "อยุธยาน้ำเป็นไงบ้าง"
ปลั๊กอินจะเลือกสกิล/เครื่องมือที่ตรงให้เอง หรือเรียก sub-agent `flood-analyst` ตรงๆ สำหรับงานวิเคราะห์เฉพาะทาง

## ข้อจำกัดที่ต้องรู้ก่อนใช้ (สรุปจาก `flood-data-caveats`)

- **กรุงเทพฯ มีสถานี thaiwater แค่ 9 แห่ง** — คลองย่อย (แสนแสบ ทวีวัฒนา ฯลฯ) เป็นคนละระบบ ใช้ข้อมูลจาก สนน. กทม. (`bkk_canals`) แทน
- สถานีบางแห่งไม่มีระดับตลิ่งอ้างอิง (`min_bank`/`lower_bank_m = 0`) → ปลั๊กอินจะบอกว่า "ไม่ทราบระยะตลิ่ง" ไม่ใช่ล้น/ไม่ล้น
- เกณฑ์ "วิกฤต" ของ สนน. กทม. บางจุดต่ำกว่าระดับตลิ่งจริง — ปลั๊กอินจะกำกับว่าเป็นเกณฑ์ของ สนน. เสมอ
- รายงานจาก Traffy Fondue เป็น**รายงานที่ยังไม่ยืนยัน** ไม่ใช่ค่าที่วัดจากเครื่องมือ
- ต้นทาง thaiwater ช้ากว่าเวลาจริงประมาณ 10–20 นาที และแต่ละสถานีอัปเดตความถี่ไม่เท่ากัน
