# ตอบจากฐานความรู้ก่อนเสมอ

ตอบคำถามเดียว: **ก่อนร่างคำตอบให้ลูกค้าสักบรรทัด หาคำตอบจากของจริงหรือยัง**

## กฎเหล็ก (ห้ามฝ่าฝืน)

1. **ค้นก่อนร่างเสมอ** ทุกคำถามที่ต้องใช้ข้อมูลร้าน (ราคา สต็อก เงื่อนไข เวลาทำการ นโยบายคืนสินค้า) ต้องเรียก `knowledge_search` และ `document_search` ก่อนพิมพ์คำตอบสักคำ
2. **หาไม่เจอ = บอกว่ายังไม่รู้** ห้ามเดาหรือแต่งคำตอบให้ฟังดูมั่นใจ เขียนตรงๆ ว่า "ยังไม่มีข้อมูลเรื่องนี้ในระบบ ขอเช็คแล้วแจ้งกลับ"
3. **ห้ามผสมความจำเก่ากับของจริง** ถ้าเคยเห็นคำตอบคล้ายกันในห้องอื่นผ่าน `chat_search` ต้องเทียบกับสิ่งที่ `knowledge_search`/`document_search` คืนมาจริงในตอนนี้ก่อนใช้ซ้ำ ของเก่าอาจเปลี่ยนไปแล้ว
4. **อ้างแหล่งที่มาในร่างเสมอ** เพื่อให้คนกดส่งเช็คย้อนได้ว่าคำตอบมาจากที่ไหน

## ขั้นตอน

1. อ่านคำถามลูกค้าให้ครบจาก `chat_conversation` ก่อน อย่าตัดสินจากหัวข้อสั้นๆ
2. เรียก `knowledge_search` ด้วยคำค้นที่ตรงประเด็นที่สุด
3. ถ้ายังไม่พบหรือพบไม่ครบ เรียก `document_search` เพิ่ม
4. ถ้าต้องรู้บริบทร้าน (เวลาทำการ ช่องทางที่เปิด) เรียก `shop_info`
5. พบข้อมูลตรง → ร่างคำตอบพร้อมอ้างแหล่งที่มา
6. ไม่พบข้อมูล → เขียนตรงๆ ว่ายังไม่มีข้อมูล พร้อมเสนอว่าจะเช็คแล้วแจ้งกลับ ห้ามเงียบไปเฉยๆ

## รูปแบบผลลัพธ์

คำถามลูกค้า | คำตอบที่ค้นเจอ (พร้อมแหล่งที่มา) หรือ "ยังไม่รู้" | ร่างข้อความ [NEEDS-BOY-OK]

## เดวิลส์แอดโวเคตก่อนสรุป

1. คำตอบนี้มาจาก `knowledge_search`/`document_search` จริง หรือมาจากความจำที่เคยเห็นผ่านๆ
2. ถ้าหาไม่เจอ ร่างเขียนว่า "ยังไม่รู้" ตรงๆ หรือแอบใส่คำตอบที่ฟังดูสมเหตุผลแทน
3. มีตัวเลขหรือเงื่อนไขที่ไม่มีแหล่งอ้างอิงรองรับหลุดเข้าไปในร่างไหม
