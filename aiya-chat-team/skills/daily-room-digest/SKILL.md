# สรุปห้องรายวันให้เจ้าของร้าน (daily room digest)

ตอบคำถามเดียว: **วันนี้ทีมตอบแชทเป็นยังไง เทียบกับเมื่อวาน แล้วพรุ่งนี้ต้องระวังอะไร**

## กฎการสรุป (ห้ามฝ่าฝืน)

1. **เทียบกับเมื่อวานเสมอ** ทุกตัวเลขต้องมีคู่เทียบ ห้ามรายงานตัวเลขเดี่ยวๆ ที่ไม่รู้ว่าดีขึ้นหรือแย่ลง
2. **บีบให้เหลือ 3 ข้อเท่านั้น** ห้ามยัดหลายเรื่องในข้อเดียวหรือรายงานทุกช่องแยกกันจนอ่านไม่จบ
3. **ห้ามยกชื่อ เบอร์ หรืออีเมลลูกค้า** ใช้จำนวนห้องและรหัสห้องเมื่อจำเป็นเท่านั้น
4. **ไม่มีข้อมูล = บอกว่าไม่มีข้อมูล** วันที่ระบบเก็บข้อมูลไม่ครบ ให้บอกตรงๆ แทนการเดาแนวโน้ม

## ขั้นตอน

1. เรียก `chat_overview` ดูภาพรวมวันนี้ (จำนวนห้อง เวลาตอบเฉลี่ย ห้องค้าง)
2. เรียก `chat_volume_trend` เทียบปริมาณข้อความเข้ากับเมื่อวานและค่าเฉลี่ยสัปดาห์
3. เรียก `chat_reply_pressure` และ `chat_unanswered` ดูจำนวนห้องที่ยังค้างตอนสรุป
4. เรียก `channel_health` เช็คว่าช่องทางไหนมีปัญหาการเชื่อมต่อระหว่างวัน
5. เรียก `shop_info` เมื่อต้องอ้างอิงเวลาทำการหรือช่องทางที่เปิดใช้งาน
6. สรุปเป็น 3 ข้อ: วันนี้ดีขึ้น/แย่ลง/เท่าเดิม, ห้องที่ต้องรีบพรุ่งนี้กี่ห้อง, สิ่งที่ยังไม่รู้

## รูปแบบผลลัพธ์

**3 ข้อเท่านั้น ภาษาคนธรรมดา**

1. วันนี้เทียบเมื่อวาน (ดีขึ้น/แย่ลง/เท่าเดิม พร้อมตัวเลขคู่)
2. ห้องที่ต้องรีบพรุ่งนี้มีกี่ห้อง มอบให้ทีมไหน
3. สิ่งที่ยังไม่รู้ (ข้อมูลที่ระบบยังเก็บไม่ครบ หรือช่องทางที่มีปัญหา)

## เดวิลส์แอดโวเคตก่อนสรุป

1. ทุกตัวเลขมีคู่เทียบเมื่อวานไหม หรือมีตัวเดี่ยวที่อ่านไม่ออกว่าดีขึ้นหรือแย่ลง
2. สรุปเกิน 3 ข้อไหม หรือยัดหลายเรื่องไว้ในข้อเดียว
3. มีชื่อ เบอร์ หรืออีเมลลูกค้าหลุดเข้าไปในสรุปไหม
