# aiya-chat-team

ปลั๊กอิน Claude Cowork / Claude Code สำหรับทีมตอบแชท AI ของร้านค้า AIYA
ทีม agent 3 ตำแหน่งเดียวกับสมองกลางของ AIYA: เนย (chat_head) หัวหน้าดูภาพรวม · ปิง (chat_responder)
ตอบห้องที่ยังทันชั่วโมงแรก · หยก (chat_followup) ไล่ห้องที่ใกล้หลุดกรอบ 7 วัน

ทุกร่างข้อความรอให้คนในร้านกดส่งเอง ไม่มีขั้นไหนส่งข้อความหาลูกค้าจริงได้เองเลย

## สิ่งที่อยู่ในปลั๊กอิน

### Agents (3 ตำแหน่ง)

| ชื่อ | ตำแหน่ง | ทำอะไร |
|---|---|---|
| เนย | `chat_head` | ดูสุขภาพการตอบทั้งกอง ชี้ว่าต้องรีบตรงไหน |
| ปิง | `chat_responder` | ร่างตอบห้องที่ลูกค้าเพิ่งทักและยังตอบทัน |
| หยก | `chat_followup` | ไล่ห้องที่ใกล้หลุดกรอบคิว และของที่หลุดไปแล้ว |

### Skills (8 ใบ)

| Skill | ตอบคำถาม |
|---|---|
| `answer-from-knowledge` | ก่อนร่างคำตอบ หาจากฐานความรู้แล้วหรือยัง |
| `brand-voice` | ร่างนี้ฟังดูเป็นร้านนี้จริงไหม |
| `handoff-to-human` | ห้องนี้ควรส่งต่อคนจริงหรือยัง |
| `triage-urgency` | ห้องไหนต้องรีบก่อน |
| `price-and-stock-reply` | ตอบราคา/สต็อกจากที่ไหน |
| `buying-signal-to-sales` | ลูกค้ามีสัญญาณอยากซื้อ ทำอะไรต่อ |
| `daily-room-digest` | สรุปห้องรายวันให้เจ้าของร้าน |
| `apology-and-remedy` | ขอโทษ/ชดเชยตามกติการ้าน |

## กติกาความปลอดภัย

- ทีมนี้ห้ามส่งข้อความหาลูกค้าเอง ทุกร่างกำกับ [NEEDS-BOY-OK]
- ห้ามสัญญาราคา ส่วนลด ของแถม หรือวันส่งของที่ไม่ได้อยู่ในห้องนั้นหรือข้อมูลร้านจริง
- ห้ามยกชื่อ เบอร์ หรืออีเมลลูกค้าออกมาในรายงาน ใช้รหัสห้อง/ช่องทางแทน
- ตัวเลขทุกตัวต้องบอกช่วงเวลาที่นับ และต้องมาจากเครื่องมือจริง ไม่ใช่จากความจำ
- ไม่มีข้อมูล = บอกว่าไม่มีข้อมูล ห้ามแต่งห้องหรือคำถามลูกค้าขึ้นมาให้ครบรูป
