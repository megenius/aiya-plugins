# aiya-chat-team

ปลั๊กอิน Claude Cowork / Claude Code สำหรับทีมตอบแชท AI ของร้านค้า AIYA
ทีม agent 3 ตำแหน่งเดียวกับสมองกลางของ AIYA: เนย (chat_head) หัวหน้าดูภาพรวม · ปิง (chat_responder)
ตอบห้องที่ยังทันชั่วโมงแรก · หยก (chat_followup) ไล่ห้องที่ใกล้หลุดกรอบ 7 วัน

ทุกร่างข้อความรอให้คนในร้านกดส่งเอง ไม่มีขั้นไหนส่งข้อความหาลูกค้าจริงได้เองเลย

นอกจากร่างข้อความให้คนส่ง ทีมนี้ยังแก้ข้อความที่**บอทตอบเอง**ได้ด้วย (สกิล `edit-bot-reply`)
และตั้งตอบกลับอัตโนมัติเรื่องใหม่ได้ (สกิล `setup-auto-reply`) ซึ่งต้องเชื่อม connector `aiya-line` เพิ่มตอนติดตั้ง (ชี้ชุดเครื่องมือ `?toolset=autoreply` เฉพาะงานตอบอัตโนมัติ) (ฝั่งเพจ Facebook/Instagram ยังไม่รองรับ ปลั๊กอินนี้ไม่ต่อ connector เพจ)

**สิทธิ์เปลี่ยนตั้งแต่ 1.0.7-alpha:** ปลั๊กอินนี้เคยอ่านอย่างเดียว ตอนนี้ connector `aiya-line` เปิดสิทธิ์**เขียน**ด้วย
`aiya-line` (ชุด autoreply) เขียนได้: สร้าง/แก้/เขียนทับ flow ตอบอัตโนมัติ เปิด-ปิด flow และแก้ persona/โหมดตอบของช่องทาง (flow ที่เปิดใช้ = บอทตอบลูกค้าจริงทันที)
สกิลแก้บอท 3 ใบสั่งให้ใช้เฉพาะ tool ที่ประกาศไว้ ทำเป็น draft ก่อน และรอเจ้าของยืนยันก่อนเปิดใช้หรือแก้ flow ที่ใช้งานอยู่หรือแก้ค่าระดับช่องทาง
แต่ด่านนี้คือข้อความในสกิล ไม่ใช่การจำกัดสิทธิ์ที่ connector (tool บางตัวมีด่านของตัวเอง เช่น `save_graph` ต้องส่ง `replace: true`) เจ้าของร้านที่ไม่ต้องการให้ AI เขียนได้ ไม่ควรเชื่อม `aiya-line`
(agent ทั้ง 3 ตำแหน่งยังจำกัด tool แบบอ่านอย่างเดียวเหมือนเดิม)

## สิ่งที่อยู่ในปลั๊กอิน

### Agents (3 ตำแหน่ง)

| ชื่อ | ตำแหน่ง | ทำอะไร |
|---|---|---|
| เนย | `chat_head` | ดูสุขภาพการตอบทั้งกอง ชี้ว่าต้องรีบตรงไหน |
| ปิง | `chat_responder` | ร่างตอบห้องที่ลูกค้าเพิ่งทักและยังตอบทัน |
| หยก | `chat_followup` | ไล่ห้องที่ใกล้หลุดกรอบคิว และของที่หลุดไปแล้ว |

### Skills (11 ใบ)

| Skill | ตอบคำถาม |
|---|---|
| `answer-from-knowledge` | ก่อนร่างคำตอบ หาจากฐานความรู้แล้วหรือยัง |
| `brand-voice` | ร่างนี้ฟังดูเป็นร้านนี้จริงไหม |
| `handoff-to-human` | ห้องนี้ควรส่งต่อคนจริงหรือยัง |
| `triage-urgency` | ห้องไหนต้องรีบก่อน |
| `price-and-stock-reply` | ตอบราคา/สต็อกจากที่ไหน |
| `buying-signal-to-sales` | ลูกค้ามีสัญญาณอยากซื้อ ทำอะไรต่อ |
| `daily-room-digest` | สรุปห้องรายวันให้เจ้าของร้าน |
| `apology-and-remedy` | ขอโทษ/ชดเชยตามกติการ้าน |
| `edit-bot-reply` | ข้อความที่**บอท**ตอบเองผิด แก้ตรงไหน · เปลี่ยนคีย์เวิร์ด · สร้าง flow ใหม่เป็น draft |
| `setup-auto-reply` | อยากให้บอทตอบเรื่องใหม่เอง สร้าง flow เป็น draft ตามลำดับ แล้วให้เจ้าของเปิดใช้เอง |
| `edit-bot-persona` | บอทพูดจาแบบไหน และตอบข้อความนอกเมนูได้หรือยัง |

## กติกาความปลอดภัย

- ทีมนี้ห้ามส่งข้อความหาลูกค้าเอง ทุกร่างกำกับ [NEEDS-BOY-OK]
- ห้ามสัญญาราคา ส่วนลด ของแถม หรือวันส่งของที่ไม่ได้อยู่ในห้องนั้นหรือข้อมูลร้านจริง
- ห้ามยกชื่อ เบอร์ หรืออีเมลลูกค้าออกมาในรายงาน ใช้รหัสห้อง/ช่องทางแทน
- ตัวเลขทุกตัวต้องบอกช่วงเวลาที่นับ และต้องมาจากเครื่องมือจริง ไม่ใช่จากความจำ
- ไม่มีข้อมูล = บอกว่าไม่มีข้อมูล ห้ามแต่งห้องหรือคำถามลูกค้าขึ้นมาให้ครบรูป
