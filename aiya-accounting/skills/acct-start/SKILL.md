# ตั้งค่าเริ่มต้นงานบัญชี

สกิลนี้ทำครั้งเดียวตอนเริ่ม แล้วกลับมาแก้เมื่อกิจการเปลี่ยน

## 0. ตรวจก่อนเสมอว่า "กำลังทำงานให้กิจการไหน"

เรียก `shop_info` เป็นอย่างแรกทุกครั้งที่เริ่มงานบัญชี แล้วอ่านผลให้ผู้ใช้ฟังว่า
รหัสกิจการคืออะไร เขตเวลาอะไร เครดิตเหลือเท่าไหร่

🔴 `shop_info` **ไม่มีชื่อกิจการ** ห้ามเดาชื่อกิจการขึ้นมาเอง ถ้าต้องเรียกชื่อ ให้ถามผู้ใช้

ถ้าเรียกเครื่องมือขึ้นต้นด้วย `acct_` หรือ `ar_` แล้วไม่มีให้เรียก แปลว่ากิจการนี้ยังไม่ได้เปิดสิทธิ์
ให้เรียก `plan_status` แล้วบอกผู้ใช้ตรงๆ ว่าต้องเปิดสิทธิ์อะไรและราคาเท่าไหร่ **ห้ามทำเป็นว่าทำได้**

## 1. ขึ้นทะเบียนบัญชีธนาคารที่กิจการมี

ดูของเดิมก่อนด้วย `acct_cash_account_list` แล้วเพิ่ม/แก้ด้วย `acct_cash_account_set`

- ทะเบียนนี้ตอบว่า *กิจการมีบัญชีอะไรบ้าง* เท่านั้น **ไม่มีช่องยอดเงิน** ยอดคงเหลือมาจากรายการเดินบัญชีเสมอ
- `txn_account` คือสะพานเดียวที่ผูกทะเบียนเข้ากับเงินจริง ต้องตรงเป๊ะกับค่า `account` ที่เห็นใน `acct_statement_list`
  🔴 **ห้ามเดาค่านี้** ยังไม่เคยนำเข้ารายการเดินบัญชี ให้เว้นว่างไว้ ซึ่งแปลว่า *ยังไม่มีข้อมูล* ไม่ใช่ *ไม่มีเงิน*
- ตั้งรหัสบัญชีเป็นอะไรก็ได้ที่ผู้ใช้เรียกแล้วเข้าใจ แต่ต้องให้ผู้ใช้เป็นคนบอก ห้ามตั้งเอง

## 2. ตั้งว่ากิจการเข้าข่ายต้องยื่นภาษีแบบไหน

อ่านของเดิมด้วย `acct_tax_profile_get` แล้วตั้งด้วย `acct_tax_profile_set`

ถามผู้ใช้ทีละข้อ แล้วค่อยตั้ง **ห้ามเดาแทนเจ้าของกิจการ**
(ตอบผิดว่าไม่มีลูกจ้าง = เขาจะไม่ถูกเตือนเรื่อง ภ.ง.ด.1 เลย)

ช่องที่เป็น `null` แปลว่า **ยังไม่ได้ตั้ง ไม่ใช่ "ไม่ใช่"** ให้บอกผู้ใช้ว่ายังขาดข้อไหน

ตั้งครบแล้วเรียก `acct_tax_calendar` ทวนให้ผู้ใช้ฟังว่าจะถูกเตือนเรื่องอะไรบ้าง

## 3. แผนที่สินค้า (เฉพาะกิจการที่ออกบิลต่อให้ลูกค้า)

`acct_product_map_list` ดูของเดิม แล้ว `acct_product_map_set` เพิ่มทีละแถว
ว่าชนิดรายการที่ผู้ให้บริการเก็บเรา ตรงกับสินค้าตัวไหนในระบบบัญชีของกิจการ

🔴 **ห้ามเดารหัสสินค้า** ไม่รู้รหัสให้เว้นไว้ แต่ชื่อสินค้าต้องกรอกเสมอ

## 4. ทะเบียนพนักงาน (ERP บุคคล · `hr_employee_create`)
- ดูรายชื่อด้วย `hr_employee_list` และรายคนด้วย `hr_employee_get` · เพิ่ม `hr_employee_create` · แก้ `hr_employee_update` · ปลด `hr_employee_terminate` (ไม่ส่ง confirm: true = ดูตัวอย่างอย่างเดียว ยังไม่บันทึก)
- สิทธิ์ของ `hr_employee_create` และทุกตัวในชุดนี้: เจ้าของร้าน หรือคนที่ถือสิทธิ์ erp_hr_payroll ในแอป ERP · ไม่มีสิทธิ์ = ได้คำตอบปฏิเสธ HR_FORBIDDEN ให้บอกผู้ใช้ตามนั้น
- ข้อมูลส่วนตัวในคำตอบของ `hr_employee_create` และทุกตัว: เงินเดือน ค่าลดหย่อน ภ.ง.ด.1 และธนาคารเป็น null · เลขผู้เสียภาษีกับเลขบัญชีเหลือ 4 หลักท้าย · ค่าจริงเห็นเฉพาะคนที่ถือสิทธิ์ erp_hr_pii_view เพิ่ม (ดูช่อง pii_visible ห้ามเดาค่าที่ถูกปิด)
## กติกาที่ใช้กับทุกสกิลในชุดนี้

- **ยอดเงินทุกช่องเป็นสตางค์** (จำนวนเต็ม) ฿1,070.00 = `107000` เวลารายงานคนให้แปลงเป็นบาทเสมอ
- ระบบนี้เป็น **กระจกของรายการเดินบัญชีกับกระดานงาน ไม่ใช่สมุดบัญชีตามกฎหมาย**
- **ไม่มีเครื่องมือโอนเงิน ไม่มีเครื่องมือยื่นภาษี** ในชุดนี้เลย คนต้องทำเองที่ธนาคาร/กรมสรรพากร
- ค่าที่เป็น `null` แปลว่า *ยังไม่รู้* ห้ามอ่านว่า *ศูนย์* หรือ *ไม่มี*

- ตั้งค่า ERP ของร้าน: `acct_settings_get` ดูว่าร้านบังคับ 2FA ไหม สมาชิกแต่ละคนมีบทบาทอะไรและตั้ง 2FA ของตัวเองแล้วหรือยัง (เจ้าของร้านและผู้ดูแล) · `acct_settings_require_mfa_set` เปิดบังคับ 2FA ได้อย่างเดียว (เจ้าของร้าน + mcp:write) ปิดต้องทำที่หน้าเว็บเพราะต้องยืนยัน 2FA สด
