# นำเข้ารายงาน PEAK (ดูก่อน แล้วให้คนกดนำเข้า)

## 🔴 เครื่องมือนี้ใช้กับไฟล์เล็กเท่านั้น

`acct_peak_import` รับไฟล์ผ่านแชทได้ในขนาดเล็กเท่านั้น (ราวไม่เกิน 8 KB) ไฟล์ที่ใหญ่กว่านี้ส่งผ่านแชทแล้วอาจเพี้ยนระหว่างทาง

**ไฟล์รายเดือนของจริงมักใหญ่กว่านี้มาก ให้บอกผู้ใช้ไปนำเข้าที่หน้าเว็บ**
https://acc.aiya.me/peak/import

- ห้ามทำเป็นว่าส่งไฟล์รายเดือนผ่านแชทได้
- `sale_taxInvoice_` (ใบกำกับภาษีขาย) ยังนำเข้าที่หน้าเว็บไม่ได้จนกว่า #4082 ขึ้น ให้ส่งห้องทีมบัญชี (หน้า /peak/import ตอนนี้รับ `invoice_` `receipt_` `quotation_`)
- 🔴 **ห้ามแนะนำ `file_url` กับลิงก์สาธารณะ** ไฟล์พวกนี้มีเลขผู้เสียภาษีและชื่อลูกค้า
  ห้ามให้ผู้ใช้ทำลิงก์เปิดสาธารณะของไฟล์เพื่อให้ระบบดึง

## ลำดับเมื่อไฟล์เล็กพอ

1. `acct_peak_import` รอบดู **ไม่เขียนอะไรเลย** คืนสรุป: จำนวนใบ ใบใหม่ ยอดรวมเป็นสตางค์ ที่ข้ามและเหตุผล
   ส่ง `file_sha256` และ `file_bytes` ของไฟล์ต้นทางมาทุกครั้ง ไม่ตรง = ปฏิเสธ ไม่แตกไฟล์
2. อ่านสรุปให้เจ้าของร้านฟังเป็นบาท บอกชัดว่าข้ามอะไร (สถานะร่าง รออนุมัติ ยกเลิก จะถูกข้าม)
3. นำเข้าจริงคือ `acct_peak_import_apply` **ตัวตน AI เรียกไม่ได้** ต้องเป็นคนในร้านสั่ง
   ต้องส่งไฟล์เดิมกับตัวเลขยืนยันที่ตรงเป๊ะกับรอบดู ไม่ตรง = ไม่เขียน
4. นำเข้าซ้ำไฟล์เดิมไม่เพิ่มแถว (กันซ้ำด้วยเลขที่เอกสาร)

## กฎเหล็ก

- ผู้ช่วยทำได้ถึงรอบดู แล้วส่งต่อให้คนกดนำเข้า ห้ามอ้างว่านำเข้าให้แล้ว
- ยอดเงินเป็น **สตางค์** เวลารายงานคนให้แปลงเป็นบาท
- ผลที่อ่านไฟล์ไม่ได้ ให้บอกตรงๆ ห้ามเดาตัวเลข
