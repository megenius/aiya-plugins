# ดูทะเบียนทรัพย์สินคงที่ (อ่านอย่างเดียว)

## ลำดับการทำงาน

1. `acct_asset_category_list` ดูทุกหมวดของร้าน: ชื่อหมวด อายุใช้งานตั้งต้น และ 3 บัญชีที่หมวดนั้นใช้ (ทรัพย์สิน / ค่าเสื่อมสะสม / ค่าเสื่อมราคา) พร้อมจำนวนทรัพย์สินในหมวด
2. `acct_asset_list` ดูทั้งทะเบียน: รหัส ชื่อ หมวด วันที่ได้มาและวันเริ่มใช้ ราคาทุน ค่าซาก อายุใช้งาน วิธีคิดค่าเสื่อม ค่าเสื่อมสะสมยกมา และสถานะจำหน่าย · ยอดเป็นสตางค์พร้อมยอดรวมท้ายชุด
   - เอาเฉพาะรายการที่ยังไม่จำหน่าย: `status` = active · เอาเฉพาะหมวด: `category` = ชื่อหมวดตามที่เห็นในข้อ 1
3. `acct_asset_get` ดูทรัพย์สินตัวเดียวตาม `code` ที่เห็นในรายการ: ได้ตัวเลขชุดเดียวกับข้อ 2 บวก 3 บัญชีของหมวดที่ทรัพย์สินนั้นสังกัด
4. `acct_asset_reconcile` เทียบทะเบียนกับงบทดลอง ณ วันสิ้นงวดของ `period` (งวดรูปแบบ YYYY-MM): ฝั่งราคาทุนเทียบบัญชีทรัพย์สิน ฝั่งค่าเสื่อมสะสมเทียบบัญชีค่าเสื่อมสะสม (เครดิตเป็นบวก) · คืนว่าจุดไหนตรง จุดไหนไม่ตรง
5. `acct_asset_opening_apply` นำเข้าทะเบียนยกมาจากไฟล์ PEAK ค่าเริ่มต้นคือ **ทดลองอย่างเดียว** (คืนแผนว่าจะเพิ่มกี่รายการ ไม่เขียนอะไร) · การเขียนจริงต้องมีคำยืนยัน `write-opening-register` สิทธิ์ผู้ดูแล ERP และระบบต้องเปิดสวิตช์ไว้ ซึ่งตอนนี้ปิดอยู่ · ห้ามเรียกแบบเขียนจริงเองโดยฝ่ายบัญชีไม่ได้สั่ง
6. `acct_asset_depreciation_preview` พรีวิวค่าเสื่อมราคาของงวด `period` ต่อทรัพย์สินจากทะเบียน (อ่านอย่างเดียว · ยังไม่บันทึกรายการบัญชีใดๆ) · ต้องเลือก `startRule` เอง (`in_service_month` / `next_month` / `daily`) · ยอดเป็นสตางค์ · กรอง `category` ได้

## กฎเหล็ก

- อ่านอย่างเดียว ไม่มีอะไรในทะเบียนนี้ที่แก้ได้จากที่นี่ ยกเว้นการนำเข้ายกมาในข้อ 5 ซึ่งทดลองก่อนเสมอ
- ทะเบียนชุดนี้ฝ่ายบัญชีเป็นคนนำเข้าจากรายการทรัพย์สินใน PEAK ตัวเลขจึงเป็นชุดเดียวกับที่ PEAK มี
- ถ้า `acct_asset_reconcile` คืน `depreciationAfterOpening=pending` แปลว่าค่าเสื่อมหลังวันยกมายังไม่มีสูตรคิดต่อ **ห้ามบอกว่าทะเบียนตรงกับงบทดลอง** ทั้งที่ยัง pending
- ตัวเลขเงินทุกจำนวนในเครื่องมือกลุ่มนี้มาเป็น **สตางค์** ต้องหารด้วย 100 ให้เป็นบาทก่อนรายงานคน
