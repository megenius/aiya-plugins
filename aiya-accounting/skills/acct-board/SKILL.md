# เคลียร์กระดานงานบัญชี

กระดาน = รายการเงินที่ **ปิดไม่ได้** เพราะยังขาดเอกสารหรือยังไม่มีใครตัดสิน
หนึ่งแถวคือหนึ่งรายการเงิน พร้อมบอกว่าต้องทำอะไร

## ลำดับการทำงาน

### 1. ดูภาพรวมก่อนเสมอ
`acct_summary` ตอบว่าเหลือเท่าไหร่และปิดไปแล้วกี่เปอร์เซ็นต์ แยกตามงวดหรือชนิดงานได้

🔴 `closed_pct = null` แปลว่า **ยังไม่มีงานเลย ไม่ใช่ 0%** ต้องพูดให้ต่างกัน

### 2. หยิบคิวที่รอทำ
`acct_task_list` โดยกรอง `status` เป็นคิวที่รอทำ และกรองงวดด้วย `period` รูปแบบ `YYYY-MM`
กรองเพิ่มได้ด้วย `action` (สิ่งที่ต้องทำ) และ `direction` (`in` เงินเข้า / `out` เงินออก)

คำตอบมี `matched` = จำนวนที่ตรงเงื่อนไข**ทั้งหมด** กับ `returned` = จำนวนในหน้านี้
ถ้าสองค่าไม่เท่ากัน **ต้องบอกผู้ใช้ว่ายังมีอีก** และไล่หน้าต่อด้วย `offset`

### 3. เปิดดูรายตัวก่อนตัดสิน
`acct_task_get` คืนงานใบเดียวแบบเต็ม พร้อม **บรรทัดเดินบัญชีที่ทำให้เกิดงานนี้**
(วัน เวลา ข้อความจากธนาคาร ยอดเข้าออก เลขอ้างอิง) อ่านข้อความจากธนาคารก่อนเดาว่ารายการนี้คืออะไร

### 4. ทำงานจริงข้างนอก แล้วค่อยบันทึก
งานจริงเกิดที่ระบบบัญชีของกิจการ (ออกใบเสร็จ ตามบิลจากคู่ค้า) **ไม่ได้เกิดที่นี่**
เสร็จแล้วบันทึกด้วย `acct_task_resolve`

| ปิดเป็น | เงื่อนไข |
|---|---|
| `done` | **ต้องมีเลขเอกสาร** ที่ปิดรายการนี้ (ใบเสร็จ/ใบแจ้งหนี้/บิล) |
| `skipped` | ตัดสินแล้วว่าไม่ต้องทำ ไม่มีเอกสารได้ **แต่ต้องเขียนเหตุผลใน note** |
| `doing` | หยิบไว้ก่อนว่ากำลังทำ |

🔴 `acct_task_resolve` **ไม่โอนเงิน ไม่ยื่นภาษี ไม่แก้ยอดเงิน** แตะได้แค่สถานะ เลขเอกสาร และบันทึกของงาน

## สิ่งที่ต้องทำแต่ละแบบ หมายความว่าอะไร

- **หาบิล** (`find_bill`) จ่ายเงินออกไปแล้วแต่ไม่มีใบกำกับ ต้องไปตามบิลจากคู่ค้ามาเก็บเป็นหลักฐาน
- **ออกใบเสร็จ** (`issue_receipt`) เงินเข้ามาแล้วแต่ยังไม่ได้ออกเอกสารขาย ต้องออกที่ระบบบัญชีของกิจการ
- **ต้องคนดู** (`review`) ยังไม่ชัดว่าเงินก้อนนี้คืออะไร ต้องจำแนกก่อนว่าเป็นรายได้ หรือเงินกู้
  หรือเงินโอนระหว่างบัญชีตัวเอง หรือเงินของกรรมการ **แต่ละอย่างลงบัญชีคนละแบบ**

## กฎเหล็ก

- **ห้ามปิดงานที่ยังไม่มีเอกสารจริง** เลขเอกสารต้องมาจากผู้ใช้หรือระบบบัญชีของกิจการ **ห้ามแต่งเลขเอง**
- **ห้ามเดาว่าเงินก้อนหนึ่งคืออะไรจากยอดที่บังเอิญใกล้กัน** ไม่ชัดให้ทิ้งไว้เป็นงานของคน
- เรื่องภาษีที่ไม่แน่ใจ (เคลมภาษีซื้อได้ไหม ต้องเสีย VAT ไหม) **ให้ถามผู้ทำบัญชีหรือผู้สอบบัญชีของกิจการ ห้ามเดา**
- ยอดเงินเป็น **สตางค์** เวลารายงานคนให้แปลงเป็นบาท
