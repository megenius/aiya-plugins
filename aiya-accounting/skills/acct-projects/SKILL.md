# ดูโครงการของร้าน (อ่านอย่างเดียว)

## ลำดับการทำงาน

1. `acct_project_list` ดูทุกโครงการ: รหัส ชื่อ ประเภท สถานะ วันที่ และยอดรายได้ก่อน VAT
   - ไม่ส่งช่วง = ไตรมาสปัจจุบัน เหมือนหน้า /projects
   - อยากดูเดือนหรือปีอื่น: `period` = `month` หรือ `quarter` หรือ `year` คู่กับ `anchor` = วันไหนก็ได้ในช่วงนั้น (YYYY-MM-DD)
   - อยากกำหนดเอง: `from` + `to` (YYYY-MM-DD) ส่งคู่กันเสมอ
2. ถ้าคำตอบมี `hint` แปลว่าร้านยังไม่มีโครงการ ให้บอกผู้ใช้ตามข้อความนั้น ห้ามเดาว่ามี
3. `acct_project_get` ส่ง `code` ตามที่เห็นในรายการ ได้ยอดรวมกับเอกสารที่ผูก (ชนิด เลขที่ วันที่ ยอด นับหรือไม่นับ พร้อมเหตุผล)
   - `found: false` = ไม่มีโครงการรหัสนี้ในร้าน ให้กลับไปดูรายการก่อน
4. `acct_project_budget_get` ส่ง `code` เดิม ได้งบรายหมวด งบรวม และต้นทุนจริงตัวเลขเดียวกับข้อ 3 (เทียบเหลือ/เกินให้อัตโนมัติ)
   - ยังไม่ตั้งงบ = `remainingSatang`/`overBudget` เป็น null ไม่ใช่ศูนย์
5. `acct_project_budget_set` ตั้ง/แก้/ลบงบหนึ่งหมวด (เฉพาะผู้ดูแล ERP + สิทธิ์ mcp:write): `category` + `amountSatang` เป็นสตางค์ · ส่ง 0 = ลบหมวดนั้น
6. `acct_project_create` สร้างโครงการใหม่ (เฉพาะผู้ดูแล ERP + สิทธิ์ mcp:write): `code` `name` `kind` และ `startOn`/`endOn` ถ้ามี · ได้ `code_taken` = รหัสซ้ำในร้าน ให้ถามผู้ใช้หารหัสใหม่ ห้ามเติมเลขต่อท้ายเอง

## กฎเหล็ก

- เขียนได้แค่ 2 อย่าง: สร้างโครงการ (ข้อ 6) กับตั้งงบ (ข้อ 5) · แก้ชื่อ/สถานะ/ลบโครงการจากที่นี่ไม่ได้
- ยอดเงินเป็น **สตางค์** เวลารายงานคนให้แปลงเป็นบาท
- เอกสารที่ "ไม่นับ" ต้องบอกเหตุผลที่ระบบให้มา ห้ามรวมเข้ายอดเอง
