# AIYA ทีมบัญชี (ปลั๊กอินสำหรับ Claude Code)

ปลั๊กอินนี้คือ **คู่มือกำกับขั้นตอน** ให้ผู้ช่วย AI ทำงานบัญชีกับระบบของ AIYA ได้แม่นขึ้น
มันไม่ได้เพิ่มความสามารถใหม่ให้ระบบ ความสามารถมาจาก **MCP ของ AIYA** ที่คุณต่อไว้
ปลั๊กอินทำหน้าที่บอกผู้ช่วยว่า *ลำดับที่ถูกคืออะไร* และ *อะไรที่ห้ามทำแทนคน*

---

## ต้องมีอะไรก่อน

1. **บัญชี AIYA** ที่เปิดสิทธิ์ **พนักงาน AI บัญชี** ไว้แล้ว
   ยังไม่ได้เปิด ผู้ช่วยจะเรียกเครื่องมือบัญชีไม่ได้ และจะบอกคุณเองว่าติดตรงไหน
2. **Claude Code** ติดตั้งบนเครื่อง

## ขั้นที่ 1 ติดตั้งปลั๊กอินจาก marketplace

### Claude Cowork

1. เปิดหน้าตั้งค่า Plugin ของ Cowork
2. เพิ่ม marketplace จาก repo นี้: `megenius/aiya-plugins`
3. ติดตั้งปลั๊กอิน `aiya-accounting`

### Claude Code (CLI)

```
/plugin marketplace add megenius/aiya-plugins
/plugin install aiya-accounting@aiya
```

ชื่อ `aiya` มาจากชื่อ marketplace ใน `plugins/.claude-plugin/marketplace.json` ของ repo นี้
ถ้าเปลี่ยนชื่อ marketplace ในอนาคต ให้เช็คชื่อจริงจากไฟล์นั้นก่อนสั่งติดตั้ง

**ถ้าทีม AIYA ส่งมาเป็นโฟลเดอร์แทนลิงก์** ให้เอาโฟลเดอร์ไปวางไว้ที่ไหนก็ได้ในเครื่อง
แล้วใช้บรรทัดแรกเป็น `/plugin marketplace add ./ชื่อโฟลเดอร์` (ต้องมี `./` นำหน้า)

ถ้าหลังติดตั้งมีข้อความบอกให้ `/reload-plugins` ก็พิมพ์ตามนั้น

## ขั้นที่ 2 ล็อกอิน connector aiya-agents

ปลั๊กอินนี้ประกาศ connector `aiya-agents` (`https://agents.aiya.me/mcp`) ไว้ใน `.mcp.json`
ต้องล็อกอินแบบ OAuth ครั้งแรกก่อนใช้

1. หลังติดตั้งปลั๊กอิน เปิดหน้าจัดการ MCP connector ของ Claude (ใน Claude Code ใช้ `/mcp` แล้วเลือก `aiya-agents`)
2. กด login/authorize แล้วล็อกอินด้วย**บัญชี AIYA ของคุณ**
3. ยืนยันสิทธิ์ (scope) ที่ขอ แล้วกลับมาที่ Claude เมื่อเห็นสถานะ connected แปลว่าใช้งานได้

> การล็อกอินนี้บอกระบบว่าคุณเป็นใคร ระบบจะจดชื่อคุณเวลาคุณอนุมัติหรือตรวจเอกสาร
> **อย่าใช้บัญชีของคนอื่นล็อกอิน** เพราะประวัติการอนุมัติจะกลายเป็นชื่อผิดคน

ทดสอบว่าติดจริงไหม ให้พิมพ์คุยกับ Claude ว่า

```
ขอดูข้อมูลร้านของฉันหน่อย
```

ถ้าตอบมาพร้อมรหัสร้านและเขตเวลา แปลว่าต่อสำเร็จ ถ้า connector ขึ้นว่าไม่ต่อติดหรือหมดอายุ
ต้อง login ใหม่ผ่านขั้นตอนเดียวกัน agent ทุกตำแหน่งจะบอกตรงๆ เมื่อเรียกเครื่องมือแล้วเจอปัญหานี้

## ขั้นที่ 3 ลองใช้

พิมพ์คำสั่งนี้เพื่อดูสรุปงานบัญชีวันนี้

```
/aiya-accounting:acct-standup
```

หรือคุยเป็นภาษาคนได้เลย ปลั๊กอินจะเลือกคู่มือที่ตรงกับเรื่องนั้นให้เอง เช่น
- "งานบัญชีค้างอะไรบ้าง"
- "ช่วยเตรียมใบตั้งเบิกจากบิลใบนี้"
- "งวดนี้ต้องวางบิลให้ใครบ้าง"
- "เดือนนี้ต้องยื่นภาษีอะไร วันไหน"

อยากเรียกทั้งทีมมาช่วยงานใหญ่ ใช้

```
/aiya-accounting:acct-team <สิ่งที่อยากได้>
```

หรือใช้คำสั่งเฉพาะงาน (ทั้งหมด 9 คำสั่ง · พิมพ์ `/aiya-accounting:` แล้วชื่อคำสั่งเป็นภาษาไทย):

| คำสั่ง | ทำอะไร |
|---|---|
| `/acct-standup` | สรุปงานวันนี้แบบสั้น |
| `/สรุปเจ้าของ` | สรุปกิจการทุกมุมสำหรับเจ้าของ (งาน+เงินสด+ลูกหนี้+ภาษี) |
| `/วางบิล` | เดินรอบวางบิลลูกค้าถึงร่าง |
| `/รับเงิน` | ไล่เงินเข้าที่ยังไม่มีใบกำกับ |
| `/จ่ายใคร` | เสนอลำดับจ่ายตามวันครบกำหนด |
| `/กระทบยอด` | จับคู่เงินออกกับเอกสาร |
| `/ปิดเดือน` | เช็คลิสต์ก่อนปิดงวด |
| `/ทวงหนี้` | สรุปลูกหนี้ที่ต้องตามเก็บ |

## ทีมบัญชี 6 ตำแหน่ง (sub-agent)

`acct-lead` หัวหน้าบัญชี (คุมภาพรวม สั่งงานต่อ) · `acct-ar-clerk` AR · `acct-ap-clerk` AP ·
`acct-recon` กระทบยอด · `acct-doc-reader` อ่านเอกสาร ·
`acct-controller-review` ผู้ตรวจ (**อ่านอย่างเดียว ไม่มีสิทธิ์ tool เขียนสักตัว**)

## สิ่งที่ระบบนี้ **ไม่ทำ** ให้ (สำคัญ อ่านก่อนใช้)

- ❌ **ไม่โอนเงิน** ไม่มีเครื่องมือสั่งโอนเลยแม้แต่ตัวเดียว คนโอนที่แอปธนาคารเองเสมอ
  สิ่งที่ระบบทำได้คือ **จดว่าโอนไปแล้ว** พร้อมหลักฐาน
- ❌ **ไม่ยื่นภาษีและไม่จ่ายภาษี** บอกได้แค่ว่าต้องยื่นอะไร วันไหน
- ❌ **ไม่ออกใบกำกับภาษี ใบเสร็จ หรือใบแจ้งหนี้ตัวจริง** เอกสารทางการออกที่ระบบบัญชีที่กิจการใช้ยื่นภาษี
- ❌ **ไม่ทำงบการเงิน** (งบทดลอง งบกำไรขาดทุน งบดุล) และ **ไม่ออกรายงาน ภ.พ.30**
- ❌ **ไม่นำเข้ารายการเดินบัญชีจากไฟล์ธนาคาร** ทำที่หน้าเว็บของ AIYA
- ❌ **ผู้ช่วยอนุมัติแทนคุณไม่ได้** และ **คนที่ตั้งเบิกอนุมัติใบของตัวเองไม่ได้** ระบบบังคับไว้

ระบบนี้เป็น **กระจกของรายการเดินบัญชีกับกระดานงาน ไม่ใช่สมุดบัญชีตามกฎหมาย**

## ประตูอนุมัติ (23 tools ต้องกดยืนยันทุกครั้ง)

`hooks/hooks.json` บังคับให้ Claude ถามยืนยัน (`decision: ask`) ก่อนเรียก tool 23 ตัวที่กระทบ
เงิน/เอกสารทางการ/ลูกค้า/แก้ยอดที่บันทึกแล้ว เช่น `acct_pay_request_approve` `ar_invoice_issue_external`
`acct_cash_account_set` เต็มรายการดูที่ `hooks/approval-gate.sh`

🔴 **รายการ 23 ตัวนี้เป็นค่าตั้งต้นที่รอ Boy เคาะ** (SPEC-cowork-plugin-accounting-20260911 §8 ข้อ 2
ยังไม่ปิด · กว้างกว่า `ACCT_FORBIDDEN_TOOLS` เดิมที่มี 9 ตัว) ใช้งานได้จริงตอนนี้แต่จะถูกทบทวนอีกครั้ง

## เรื่องความปลอดภัยที่ต้องรู้

- ลิงก์อัปโหลดไฟล์ **ใช้ได้ครั้งเดียว หมดอายุใน 30 นาที**
- ลิงก์เปิดดูไฟล์แนบ **เปิดได้นาน 30 วัน และใครถือลิงก์ก็เปิดดูได้โดยไม่ต้องล็อกอิน**
  อย่าส่งต่อในกลุ่มสาธารณะ
- ทุกการอนุมัติ ตรวจ และแก้ไข ระบบจดชื่อคนที่ทำและเวลาไว้ ผู้สอบบัญชีตามได้

## ติดขัดตรงไหน

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| Claude บอกว่าไม่มีเครื่องมือบัญชี | ยังไม่ได้เปิดสิทธิ์ พนักงาน AI บัญชี ให้ถามว่า "แผนของฉันเปิดอะไรไว้บ้าง" |
| ล็อกอินแล้วแต่ยังเรียกไม่ได้ | พิมพ์ `/mcp` แล้วเชื่อมต่อใหม่อีกครั้ง |
| พิมพ์ `/aiya-accounting:` แล้วไม่ขึ้น | ยังไม่ได้ติดตั้งปลั๊กอิน หรือยังไม่ได้ `/reload-plugins` |
| ตัวเลขไม่ตรงกับที่คิด | ให้ถามผู้ช่วยว่า "ตัวเลขนี้มาจากไหน" มันต้องตอบได้ทุกครั้ง ถ้าตอบไม่ได้ อย่าเชื่อ |
