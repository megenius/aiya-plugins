🔴 **บล็อกบางส่วน**: acct_gl_trial_balance ยังไม่ขึ้นทะเบียนเป็น MCP tool
(SPEC-cowork-plugin-accounting-20260911 §1ฉ ไม่มี `gl_*` เลยสักตัว) คำสั่งนี้ทำได้ถึงเช็คลิสต์ภาษี
+ ค้างกระทบยอดเท่านั้น ใช้สกิล `acct-month-close`

โจทย์เพิ่มเติมจากผู้ใช้ (ถ้ามี): $ARGUMENTS

## ลำดับที่ต้องทำ

1. `shop_info` ยืนยันกิจการ แล้วถามงวดที่จะปิดถ้าผู้ใช้ยังไม่บอก
2. `acct_tax_profile_get` เช็คว่าจด VAT ไหม ยังไม่ตั้งให้บอกว่ายังไม่รู้ ห้ามเดา
3. `acct_vat_report` + `acct_vat_lines` ดูภาษีซื้อ/ขายของงวด
4. `acct_reconcile` ดูค้างทั้งหมดของงวด
5. รายงานเช็คลิสต์ แล้วหยุด · **ไม่ปิดงวดเอง** (`ar_run_close` ต้องผ่านประตูอนุมัติ)

## รูปแบบคำตอบ

```
🗓 งวด <เดือน/ปี> · จด VAT: <ใช่/ไม่/ยังไม่ตั้ง>
🧾 ภาษีซื้อไม่มีเอกสาร: <n> · 🔗 ค้างกระทบยอด: <n>
📊 งบทดลอง: ยังไม่มีเครื่องมือให้ดึง
👉 ตรวจครบแล้วให้คนกด ar_run_close เอง
```

## กฎ

- **ตัวเลขที่ต่างกันมากโดยไม่มีคำอธิบาย ห้ามเดาเหตุผลเอง** ให้ถามหรือยกธง
- **ห้ามคำนวณงบทดลอง/งบการเงินเองจากตารางอื่น** ไม่มี tool ให้ = บอกว่ายังทำไม่ได้
