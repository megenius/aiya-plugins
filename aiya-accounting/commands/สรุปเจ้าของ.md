สรุปสถานะกิจการทุกมุมให้เจ้าของอ่านจบในคำตอบเดียว เหมือน `/acct-standup` เดิมแต่เพิ่มมุม
เงินสด + ลูกหนี้ตามธง PLAN-CASH §2 ดึงของจริงทุกก้อน ห้ามเดา

โจทย์เพิ่มเติมจากผู้ใช้ (ถ้ามี): $ARGUMENTS

## ลำดับที่ต้องทำ

1. `shop_info` ยืนยันกิจการ เรียกเครื่องมือบัญชีไม่ได้ให้เรียก `plan_status` แล้วหยุด
2. `acct_summary` งานค้างบนกระดาน
3. `ar_summary` ภาพรวมลูกหนี้
4. `acct_cashflow` เงินสดวันนี้
5. `acct_ap_due` ต้องจ่ายเร็วๆ นี้ · `ar_collect_due` ต้องเก็บเร็วๆ นี้
6. `acct_tax_calendar` กำหนดยื่นที่ใกล้ถึง

## รูปแบบคำตอบ

```
🏢 กิจการ <รหัส> · เขตเวลา <tz>

📋 กระดานงาน: เหลือ <n> รายการ
💰 เงินสดวันนี้: <บาท> (ข้อมูลถึง <วันที่>)
📤 ต้องจ่ายเร็วๆนี้: <n> ราย รวม <บาท> · 📥 ต้องเก็บเร็วๆนี้: <n> ราย รวม <บาท>
🗓 ใกล้ถึงกำหนดยื่น: <แบบ + วันกระดาษ + วันออนไลน์>

👉 สามอย่างที่ควรทำวันนี้: ...
```

## กฎ

- ตัวเลขทุกตัวมาจากเครื่องมือ **ห้ามประมาณ ห้ามจำจากรอบก่อน**
- ยอดเงินที่ระบบคืนมาเป็นสตางค์ แปลงเป็นบาทก่อนบอกคน
- ค่าที่เป็น `null` ให้พูดว่า **ยังไม่รู้** ห้ามพูดว่าศูนย์
- กำหนดยื่นยังไม่ได้ตรวจวันหยุดราชการ ต้องเตือนผู้ใช้ทุกครั้ง
