# AIYA Plugins

Marketplace ของปลั๊กอิน AIYA สำหรับ Claude Cowork และ Claude Code

## ติดตั้งใน Claude Cowork
1. Customize > Plugins > กด + > Add marketplace from GitHub
2. ใส่ `megenius/aiya-plugins`
3. Browse plugins > aiya-marketing-team > Install แล้วล็อกอิน connector aiya-page ด้วยบัญชี AIYA

## ติดตั้งใน Claude Code
```
/plugin marketplace add megenius/aiya-plugins
/plugin install aiya-marketing-team@aiya
```

ต้นทางของโค้ดอยู่ในโฟลเดอร์ plugins/ ของรีโปหลัก AIYA (mirror มาที่นี่ตอน release)
