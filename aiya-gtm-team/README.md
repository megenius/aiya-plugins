# aiya-gtm-team · ปลั๊กอินประกอบ GTM ของ Product ตัวเอง

ปลั๊กอิน Claude 8 skill สำหรับคนที่ Build Product ด้วย AI ได้แล้ว แต่ยังไม่รู้จะขายยังไง
ทำตามลำดับแล้วได้ **GTM One-Pager** ของ Product ตัวเอง 1 หน้า พร้อม Pricing Table (ช่องราคาเติมเอง), Demo Script และแผน 7 วัน
ทุก skill เป็นภาษาไทย ใช้กับ Claude เปล่าได้เลย ไม่ต้องต่อระบบอื่น

ข้ามลำดับได้ เรียก skill ไหนก่อนก็ได้ ช่องที่ยังไม่ได้ทำจะขึ้นว่า `ยังว่าง`

## ไฟล์ `my-product.md` ทำงานยังไง
- `gtm-start` สร้างไฟล์นี้ครั้งแรก มี 8 ส่วน ตรงกับ 8 skill
- skill ทุกตัวอ่านไฟล์นี้ก่อน คุณไม่ต้องเล่าเรื่อง Product ซ้ำ
- แต่ละ skill เติมเฉพาะส่วนของตัวเอง และ **ถามคุณก่อนเขียนทุกครั้ง**
- ช่องที่คุณไม่ได้ให้ข้อมูล จะเขียนว่า `ยังว่าง` ไม่มีการเดาเติม
- ใช้บน claude.ai เว็บ (ไม่มีโฟลเดอร์ไฟล์): skill จะขอให้คุณวางเนื้อหาไฟล์ในแชท หรือถามสั้นๆ 3 ข้อแล้วทำต่อ และแสดงผลเป็นบล็อกให้คุณก๊อปเก็บไว้เอง
- กลับบ้านแล้วใช้ต่อกับ Product ถัดไปได้เลย แค่เริ่มไฟล์ใหม่ด้วย `gtm-start`

## กติกาความปลอดภัย (ทุก skill)
1. **ทุกอย่างเป็นร่าง** ไม่มี skill ไหนยิงแอด โพสต์ ส่งข้อความ หรือใช้เงินจริง
2. **ไม่แต่งตัวเลข** ขนาดตลาด, CPC, ROAS, conversion, ยอดผู้ใช้, ราคา ถ้าต้องใช้จะเว้นช่อง `[ใส่ตัวเลขจริง]` หรือ `[ใส่ราคา]` ให้คุณเติม
3. **ไม่แต่งลูกค้า** ไม่มีชื่อลูกค้า รีวิว หรือเคสสำเร็จที่ไม่มีจริง
4. **จบด้วยกล่อง "ตรวจก่อนใช้"** บอกว่าช่องไหนยังว่าง ประโยคไหน AI เดา และขั้นถัดไป
5. AI ร่าง คนตัดสิน · ตัวเลขที่ไม่มีที่มา ให้ขีดทิ้ง
