# gtm-start · สร้างไฟล์ตั้งต้น my-product.md

## เมื่อไรใช้
- ต้นภาคบ่าย (13:30-13:50) ก่อน skill อื่นทุกตัว
- ผู้เรียนมี Product ใหม่ อยากเริ่มชุด GTM ใหม่
- skill อื่นหาไฟล์ `my-product.md` ไม่เจอ แล้วส่งมาที่นี่

## ต้องมีอะไรก่อน
- ไม่ต้องมีอะไร · ถ้าผู้เรียนมี Worksheet ตอนเช้า (Value Proposition Canvas หน้า 27, ICP หน้า 37, Pricing หน้า 38) ให้วางข้อความมาได้เลย
- ถ้ามีไฟล์ `my-product.md` อยู่แล้วในโฟลเดอร์งาน: อ่านก่อน แล้วถามว่า "แก้ของเดิม หรือเริ่ม Product ใหม่" (ห้ามเขียนทับเงียบๆ)

## ขั้นตอน
1. ทักสั้นๆ 1 บรรทัด แล้วในข้อความเดียวกันถามว่า "วาง Worksheet เช้ามาเลย หรือตอบ 3 ข้อนี้" พร้อมแสดง Q1-Q3 (ข้อ 3) ทันที ให้จบใน 1 รอบถามตอบ
2. ถ้าผู้เรียนวางข้อความมา: ดึงข้อมูลลงช่องตาม schema ด้านล่าง ใช้คำของผู้เรียนเอง ห้ามขยายความ แล้วไปข้อ 5
3. คำถาม 3 ข้อ (ถามครั้งเดียวในข้อ 1 ห้ามถามเพิ่ม):
   - Q1: Product ชื่ออะไร ทำอะไร (1 ประโยค) · ตอนนี้อยู่ขั้นไหน (ไอเดีย / มี prototype / มีผู้ใช้แล้ว)
   - Q2: ขายให้ใคร (ประเภทธุรกิจหรือคน · ขนาด · ตอนนี้เขาใช้อะไรแก้ปัญหาอยู่)
   - Q3: ลูกค้าเจ็บตรงไหน และใช้แล้วได้อะไร · มีราคาร่างไหม (ไม่มีก็ได้)
4. ได้คำตอบแล้ว **ผลิตเลย ไม่ถามรอบสอง** · ช่องที่ผู้เรียนไม่ได้ให้ = `ยังว่าง`
5. แสดงร่างไฟล์ทั้งไฟล์ในบล็อกโค้ด markdown (ตามรูปแบบผลลัพธ์) + บอกว่าช่องไหนยังว่าง
6. ถามคำเดียว: "ถูกต้องไหม ตกลงให้บันทึกเลย?"
7. ผู้เรียนตกลง:
   - **มีโฟลเดอร์งาน (Claude Desktop / Cowork / Code):** เขียนไฟล์ `my-product.md` ในโฟลเดอร์งาน แล้วบอก path
   - **ไม่มีไฟล์ (claude.ai เว็บ):** บอกว่า "ก๊อปบล็อกด้านบนเก็บไว้ในโน้ต แล้ววางให้ skill ถัดไปตอนมันถาม" · ไม่ต้องพยายามสร้างไฟล์
8. ปิดด้วยกล่อง "ตรวจก่อนใช้"

## กติกาการเติมช่อง
- ICP แตกเป็น 5 ส่วนตามหัวช่อง: ใคร · ขนาดธุรกิจ · ใช้เครื่องมืออะไรอยู่ · พฤติกรรม · งานที่อยากให้สำเร็จ · ส่วนที่ไม่รู้เขียน `ยังว่าง` ในวงเล็บตรงนั้น
- Value Proposition เขียนรูป `Pain: ... → Gain: ...` จากคำของผู้เรียน
- ราคา: ใส่เฉพาะตัวเลขที่ผู้เรียนพิมพ์เอง · ไม่ได้ให้ = `ยังว่าง` · ห้ามเสนอราคาเอง
- สถานะ Product: ถ้าบอกจำนวนผู้ใช้ ใส่ตามที่บอก · ไม่บอก = ใส่แค่ขั้น เช่น `มี prototype`
- ถ้าต้องสรุปความหมายจากข้อความยาว ให้ติดป้าย `(AI สรุป)` ท้ายช่องนั้น
- ช่อง 2-8 ปล่อยหัวไว้ว่าง (skill อื่นจะเติม)
- วันที่ = วันนี้ รูป `30 ก.ย. 2569` (ถ้ารู้วันที่จริงของระบบ ใช้วันนั้น)

## รูปแบบผลลัพธ์
ใช้ schema นี้ตรงตัว ห้ามเพิ่มหรือเปลี่ยนชื่อหัวข้อ (skill อื่นหาช่องจากหัวข้อเหล่านี้)

```markdown
# <ชื่อ Product>
อัปเดต: <วันที่>

## 1. ตั้งต้น (gtm-start)
- ชื่อ Product: <...>
- ทำอะไร (1 ประโยค): <...>
- ICP (ใคร · ขนาดธุรกิจ · ใช้เครื่องมืออะไรอยู่ · พฤติกรรม · งานที่อยากให้สำเร็จ): <ใคร> · <ขนาด> · <เครื่องมือ> · <พฤติกรรม> · <งาน>
- Value Proposition (Pain → Gain): Pain: <...> → Gain: <...>
- คู่แข่ง/ทางเลือกที่ลูกค้าใช้อยู่ตอนนี้: <...>
- ราคาร่าง / โมเดลราคา: <...>
- สถานะ Product (ไอเดีย / มี prototype / มีผู้ใช้แล้วกี่คน): <...>
## 2. Growth Loop (plg-loop)
## 3. Magnet: Free Tool (free-tool)
## 4. Content (content-matrix)
## 5. Paid (ads-brief)
## 6. Sales Motion (sales-playbook)
## 7. Pricing Table (gtm-one-pager)
## 8. 7 วันถัดไป (action-plan-7d)
```

ตัวอย่างช่องที่ผู้เรียนให้ข้อมูลไม่ครบ:
```
- ICP (ใคร · ขนาดธุรกิจ · ใช้เครื่องมืออะไรอยู่ · พฤติกรรม · งานที่อยากให้สำเร็จ): ร้านทำเล็บ · 1-3 สาขา · จดคิวใน LINE และสมุด · (พฤติกรรม: ยังว่าง) · อยากลดลูกค้าเบี้ยวนัด
- ราคาร่าง / โมเดลราคา: ยังว่าง
```

## ห้าม
- ห้ามเดาช่องที่ผู้เรียนไม่ได้ให้ (ขนาดตลาด, ราคา, จำนวนผู้ใช้, ชื่อคู่แข่งที่ผู้เรียนไม่ได้พูด)
- ห้ามถามเกิน 3 ข้อก่อนผลิต ห้ามถามรอบที่สอง ถ้ายังไม่ครบให้ใส่ `ยังว่าง`
- ห้ามแต่งชื่อลูกค้า รีวิว หรือเคส
- ห้ามเขียนไฟล์ก่อนผู้เรียนตกลง ห้ามเขียนทับไฟล์เดิมโดยไม่ถาม
- ห้ามเปลี่ยนหัวข้อ schema
