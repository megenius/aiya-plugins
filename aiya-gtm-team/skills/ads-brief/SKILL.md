# ads-brief · บรีฟแอดตรง ICP (Block 4.2 Push Ads)

## เมื่อไรใช้
- หลังทำ content-matrix แล้ว อยากลองดันด้วยแอด
- ผู้เรียนพิมพ์ประมาณ "ทำบรีฟแอด", "ร่างข้อความแอด", "ควรตัดใครออก", "ตั้งกฎหยุดแอด"
- ผลที่ได้ = ช่อง `## 5. Paid` ใน `my-product.md` (หัวข้อในไฟล์อาจมีชื่อ skill ในวงเล็บต่อท้าย ให้เขียนใต้หัวข้อเดิม ห้ามสร้างหัวข้อซ้ำ)

## ต้องมีอะไรก่อน
1. อ่าน `my-product.md` ถ้ามี (ใช้ส่วน 1 ICP · Value Prop · คู่แข่ง และส่วน 2-4 ถ้ามี)
2. ถ้าไม่มีไฟล์ (เช่นใช้บน claude.ai เว็บ): ขอให้วางเนื้อหาไฟล์ในแชท ถ้าไม่มีเลย ถามรวดเดียวไม่เกิน 3 ข้อ แล้วรอคำตอบ 1 รอบ (ถ้าผู้เรียนบอก "ไปต่อด้วยสมมติฐานเลย" ให้ผลิตทันที)
   - Product ทำอะไร ให้ใคร (1 ประโยค)
   - ลูกค้ามักลังเลเรื่องอะไร (Objection 1 ข้อ)
   - ประโยคหลักบนหน้า Landing ตอนนี้ (ไม่มีก็ได้ เดี๋ยวร่างให้)
3. ได้คำตอบแล้ว ข้อไหนยังไม่ได้คำตอบ ให้ใช้สมมติฐานที่ติดป้าย `[เดา]` แล้วผลิตต่อ ห้ามถามรอบสอง

## ขั้นตอน
1. **Target → Message → Page (สไลด์หน้า 77):** เขียน 1 แถวว่า ICP คือใคร · Objection หลัก · ข้อความแอดต้องพูดอะไร · หน้า Landing ต้องมีประโยคไหนที่ใช้คำเดียวกัน · ประโยค Landing ร่างจากคำที่อยู่ใน VP / my-product เท่านั้น ห้ามแต่งฟีเจอร์ที่ผู้เรียนไม่ได้บอก
2. **เช็กความต่อเนื่อง (continuity check):** เทียบคำหลักในแอดกับประโยคบน Landing ถ้าคำไม่ตรง ให้ชี้ว่าต้องแก้ฝั่งไหน (Short video / Caption / Landing ต้องใช้คำเดียวกัน ตามสไลด์หน้า 72)
3. **แอด 2 แบบ ต่างกันแค่ 1 อย่าง:** เลือกตัวแปรเดียว (Hook / Objection ที่ตอบ / CTA / ภาพ) แล้วบอกชัดว่าต่างกันที่อะไร เพื่อให้ผลเทียบกันได้ (สไลด์หน้า 77: แยกผลจาก Targeting, Offer, Conversion Path)
4. **เลือก Platform ตามพฤติกรรม ICP (สไลด์หน้า 75-76):** LinkedIn = Role/Company ชัด · Google = คนค้นหาแล้ว · Meta = ทดสอบ Creative กว้าง · Reddit/กลุ่ม = คุย Pain ด้วยภาษาจริง ให้คุณค่าก่อน · เลือกจากที่ ICP อยู่จริง ไม่ใช่ที่ดัง
5. **Negative ICP (กลุ่มที่ไม่ใช่ลูกค้า ต้องตัดออก) Exclusion List (สไลด์หน้า 78):** 4 หัวข้อ ใช้ข้อมูลที่ผู้เรียนให้ ส่วนที่เดาติด `[เดา]`
6. **Channel mix Core / Test / Learn + Stop rule (กฎว่าเมื่อไรหยุด) (สไลด์หน้า 79):** แบ่งเป็นสัดส่วนคำพูด ไม่ใส่ตัวเลขเงินเอง งบทดลองเป็นช่องว่างให้ผู้เรียนเติม · Stop rule ต้องตั้งก่อนเริ่ม และวัดจากคุณภาพ Lead ไม่ใช่ CTR อย่างเดียว
7. เสนอข้อความสำหรับช่อง `## 5. Paid` แล้วถามว่า "เขียนลงไฟล์เลยไหม" ตอบตกลงค่อยเขียน + แก้บรรทัด `อัปเดต:` · ไม่มีไฟล์: ถ้าผู้เรียนวาง my-product.md มา แสดง my-product.md ทั้งไฟล์ฉบับอัปเดต (ช่องของ skill นี้แบบย่อ) ในบล็อกเดียว ให้ก๊อปไปแทนของเดิมทั้งก้อน · ถ้าไม่มี my-product เลย แสดงแค่บล็อกช่องของ skill นี้แบบย่อ

| | แบบ A | แบบ B |

| ข้อความ | ... | ... |

**Negative ICP: ตัดออก** (สไลด์หน้า 78)

ช่องใน my-product.md (ย่อ): แถว Target → Message → Page · หัวข้อแอด A/B · Negative ICP 4 ข้อ · Stop rule

ตัวเลขทุกตัวในบรีฟ (งบ, วัน, จำนวน Lead, CPC, ROAS) = ช่องว่าง `[ใส่ตัวเลขจริง]` ให้ผู้เรียนเติม · ถ้าผู้เรียนถาม "ควรตั้งเท่าไร" ให้บอกวิธีหาเอง: ดูค่าประเมินในหน้าตั้งค่าแอดของ Platform นั้นตอนสร้างจริง หรือเริ่มจากงบที่ยอมเสียเพื่อเรียนรู้ได้โดยไม่เจ็บ

## ตัวอย่างสั้น (ใช้เป็นแนว ห้ามก๊อปตัวเลข เพราะไม่มีตัวเลข)
Product สมมติ "ระบบจองคิวร้านทำเล็บ" · ICP เจ้าของร้านทำเล็บ 1-3 สาขา รับจองทาง LINE เอง · Objection "ลูกค้าไม่ยอมจองผ่านลิงก์หรอก"
- แอด A (Hook: ปัญหา) "ตอบ LINE จองคิวทั้งคืน?" · แอด B (Hook: ผลลัพธ์) "ให้ลูกค้าจองคิวเองใน LINE" · ต่างกันแค่ Hook
- ตัดออก: ร้านสปาใหญ่ที่มีระบบ POS อยู่แล้ว `[เดา]` · คำค้น "ทำเล็บใกล้ฉัน" (คนหาที่ทำเล็บ ไม่ใช่เจ้าของร้าน)

## ห้าม
- ห้ามยิงแอด สร้างแคมเปญจริง ตั้งงบจริง หรือเรียก tool ที่ใช้เงิน · ทุกอย่างเป็นร่าง
- ห้ามเดา CPC, CPM, CTR, ROAS, conversion rate, ขนาด audience, งบแนะนำ
- ห้ามแต่งรีวิว ชื่อลูกค้า หรือผลลัพธ์ลูกค้าในข้อความแอด (เช่น "ร้านกว่า 500 ร้านใช้แล้ว")
- ห้ามใส่ราคาในแอด ถ้าผู้เรียนไม่ได้ให้ราคามา
- ห้ามสร้างแคมเปญหรือแอดใดๆ แม้เป็น PAUSED · ห้ามเรียก tool ของระบบภายนอกใดๆ (รวม AIYA เช่น mkt_*, page_*) ในรุ่นนี้ ทั้งส่ง ลงปฏิทิน หรือบันทึกร่าง · ผลเก็บใน my-product.md อย่างเดียว · ถ้าผู้เรียนถามเรื่องส่งเข้า AIYA บอกให้ทำเองที่ mar.aiya.me
