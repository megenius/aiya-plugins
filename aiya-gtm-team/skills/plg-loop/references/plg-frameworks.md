# อ้างอิง PLG · Block 3.1 (สไลด์พี่บอล หน้า 43-50)

อ่านเพื่อเลือกคำและผูกกับสไลด์ ห้ามคัดลอกยาวให้ผู้เรียน

## PLG Loop ต่างจาก Referral Program (หน้า 44)
- Loop ฝังอยู่ใน **พฤติกรรมหลัก (Core Action)** ของ Product ไม่ใช่ Campaign ที่แปะเพิ่ม
- ผู้ใช้ได้ Value ก่อน แล้วการกระทำของเขาพาคนใหม่เข้ามา
- Referral Program ที่พึ่ง Incentive มักหยุดเมื่อ Incentive หาย
- ใช้เป็นข้อเช็ก: ถ้า Loop ที่ร่างต้องมี "รางวัลแนะนำเพื่อน" ถึงจะหมุน แปลว่ายังไม่ใช่ Loop

## PLG Loop 4 รูปแบบ (หน้า 45)
| แบบ | นิยามจากสไลด์ | ใช้เมื่อ Product... | ตัวอย่างในสไลด์ |
|---|---|---|---|
| 1. Share/Deploy | Output ถูกส่งต่อหรือเผยแพร่ | สร้างของที่คนอื่นต้องเห็น/เปิด เช่น ลิงก์, รายงาน, หน้าเว็บ, ใบนัด | Base44 (หน้า 43), Bolt.new (หน้า 48) |
| 2. Creator/Earning | ผู้สร้างได้ประโยชน์เมื่อมีผู้ติดตามหรือผู้ซื้อ | ผู้ใช้ได้เงิน/ผู้ติดตามจากการใช้ Product (marketplace, template store) | |
| 3. Viewer-to-Creator | ผู้ชมเริ่มสร้างของตัวเอง | คนที่เห็นผลงานอยากทำแบบเดียวกัน | ElevenLabs Creator Flywheel (หน้า 49) |
| 4. Word-of-mouth | ประสบการณ์ดีจนเกิดการแนะนำโดยธรรมชาติ | Output ไม่ถูกแชร์ตรง แต่ผลลัพธ์ชัดพอจะเล่าต่อ (B2B ภายในองค์กร, งานบริการ) | |

เลือกแบบที่ **Core Action ของ Product ทำให้เกิดอยู่แล้ว** ไม่ใช่แบบที่ฟังเท่ที่สุด

## เคสในสไลด์ (ใช้เป็นภาพ ไม่ใช่ Benchmark)
- Base44 (หน้า 43): ผู้ใช้เห็นผลเร็ว + แชร์ผลงาน ทำให้คนใหม่เห็น Value ก่อนสมัคร · สไลด์ระบุเองว่า "ไม่ใช่ Benchmark รายได้ที่รับรอง"
- Bolt.new (หน้า 48): Time-to-value สั้น · Output ที่เห็นได้กระตุ้นการแชร์ · **PQL ควรจับจากพฤติกรรมสร้างและ Deploy ไม่ใช่จำนวน Login** · ตัวเลข Growth ต้องตรวจก่อนเผยแพร่
- ElevenLabs (หน้า 49): Output → Audience → Creator · Referral เกิดจากผลงาน ไม่ต้องเริ่มจากรางวัล
- ห้ามยกตัวเลขของเคสเหล่านี้ (เช่น ARR, ระยะเวลา exit) ไปใส่ในแผนผู้เรียน

## Time-to-value
- "นาทีแรกที่ผู้ใช้เห็นค่า" = เหตุการณ์แรกที่ผู้ใช้ได้ผลลัพธ์จริงของ Product (ไม่ใช่สมัครเสร็จ ไม่ใช่ Login)
- เขียนเป็นประโยค: "ผู้ใช้ <ทำอะไร> แล้วเห็น <ผลลัพธ์อะไร>" + นับขั้นที่ต้องทำก่อนถึงจุดนั้น (นับขั้นได้ เพราะมาจากการออกแบบ ไม่ใช่สถิติ)
- ถ้าต้องทำเกิน 3-4 ขั้น เสนอวิธีตัดขั้น 1 ข้อ (ตัวอย่างข้อมูลสำเร็จรูป, ไม่ต้องสมัครก่อนลอง, template)

## AARRR (หน้า 47 · หน้าสไลด์เป็นภาพ ใช้นิยามมาตรฐาน)
| ขั้น | คำถาม | ตัวอย่างชื่อ Metric (ชื่อเท่านั้น ไม่มีตัวเลข) |
|---|---|---|
| Acquisition | คนใหม่มาจากไหน | จำนวนคนเปิดลิงก์ที่ผู้ใช้แชร์ต่อสัปดาห์ |
| Activation | ถึงนาทีแรกที่เห็นค่าไหม | % ผู้สมัครที่ทำ Core Action ครั้งแรกภายในวันแรก |
| Retention | กลับมาใช้ซ้ำไหม | % ผู้ใช้ที่ทำ Core Action ซ้ำในสัปดาห์ที่ 2 |
| Referral | การใช้งานพาคนใหม่มาไหม | จำนวน Output ที่ถูกแชร์ต่อผู้ใช้ 1 คน |
| Revenue | จ่ายเงินไหม | % ผู้ใช้ฟรีที่อัปเกรดหลังถึง PQL |

PQL (Product Qualified Lead) ให้นิยามจากพฤติกรรม เช่น "สร้างและแชร์ Output ครบ 3 ครั้ง" (ตัวเลขในนิยามให้ผู้เรียนตั้งเอง หรือเขียน `[ตั้งเกณฑ์เอง]`)
