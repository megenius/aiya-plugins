# gtm-one-pager · GTM หน้าเดียว + Pricing Table (ช่วงประกอบ One-Pager)

## เมื่อไรใช้
- ทำ skill ก่อนหน้ามาบ้างแล้ว (กี่ตัวก็ได้) อยากเห็นภาพรวมหน้าเดียว
- ผู้เรียนพิมพ์ประมาณ "ทำ one-pager", "รวมเป็นหน้าเดียว", "ทำ pricing table", "เอาไปพิมพ์"
- ผลที่ได้ = ไฟล์ `gtm-one-pager.html` + markdown + ช่อง `## 7. Pricing Table` ใน `my-product.md` (หัวข้อในไฟล์อาจมีชื่อ skill ในวงเล็บต่อท้าย ให้เขียนใต้หัวข้อเดิม ห้ามสร้างหัวข้อซ้ำ)
- เรียกซ้ำได้ทุกเมื่อ เช่น หลังทำ action-plan-7d เพื่อให้ช่อง 7 วันเต็ม

## ต้องมีอะไรก่อน
1. อ่าน `my-product.md` ทั้งไฟล์ (ส่วน 1-8)
2. ไม่มีไฟล์: ขอให้วางเนื้อหา my-product.md หรือผลจาก skill ก่อนหน้าในแชท · ไม่มีอะไรเลย ถามรวดเดียว 3 ข้อ (ชื่อ Product + ทำอะไร · ICP · Pain → Gain) แล้วประกอบเลย ส่วนที่เหลือขึ้น "ยังว่าง"
3. ห้ามรอให้ครบทุกช่อง One-Pager ที่มีป้าย "ยังว่าง" หลายช่อง = ใช้ได้ และบอกผู้เรียนชัดว่าต้องทำอะไรต่อ

## ขั้นตอน
1. **จับคู่ช่อง:** ใช้ตาราง "แผนที่ช่อง" ด้านล่าง ดึงข้อความจากไฟล์ ย่อให้สั้น (ช่องละ 2-4 บรรทัด) ห้ามเติมข้อมูลใหม่
2. **ช่องว่าง:** ถ้าในไฟล์เขียน `ยังว่าง` หรือไม่มีข้อมูล ให้แสดงป้าย **ยังว่าง** + บรรทัดบอกว่า skill ไหนเติมได้ ห้ามเขียนเนื้อหาแทน
3. **Pricing Table (สไลด์หน้า 40: Tier ต้องสะท้อนความต่างของลูกค้า ไม่ใช่แค่แบ่งราคา):**
   - ถ้า my-product.md มีราคา/Tier จริงจากผู้เรียน ใช้ตามนั้น
   - ถ้ามีแค่โมเดลราคา หรือไม่มีเลย: ร่างโครง 2-3 Tier (ชื่อ Tier · เหมาะกับใคร · ต่างกันที่อะไร) จาก ICP และ Value Prop ติดป้าย `[เดา]` ที่ชื่อ Tier และความต่าง · **ช่องราคาเป็น `[ใส่ราคา]` เสมอ**
   - ชื่อ Tier ตั้งตามกลุ่มลูกค้าเท่านั้น ห้ามมีคำที่บอกราคา (ฟรี/Free/Trial/ประหยัด) เว้นแต่ผู้เรียนให้มา
   - ห้ามใช้ตัวเลขใดๆ จากสไลด์หน้า 39 และ 41 (เป็นช่องว่างของวิทยากร)
4. **Positioning 1 ประโยค:** ถ้าช่อง 1 มีบรรทัด `Positioning (positioning-laws)` ให้ใช้ประโยคนั้นตรงตัว และใส่ "คำที่ครอง" ใต้ Positioning · ถ้าไม่มี ประกอบจากข้อมูลที่มี รูปแบบ "สำหรับ <ICP> ที่ <Pain>, <ชื่อ> คือ <หมวด> ที่ <ผลลัพธ์หลัก> ต่างจาก <ทางเลือกเดิม> ตรงที่ <จุดต่าง>" ส่วนไหนไม่มีข้อมูล ให้เว้น `[...]` ไม่เดา
5. **สร้าง HTML:** ใช้แม่แบบใน `references/one-pager-template.html` (อ่านไฟล์นั้น) ไฟล์เดียว CSS ในตัว ไม่มี script ไม่โหลดอะไรจากภายนอก ขนาด A4 ต้องพอดี 1 หน้า (ถ้ายาวเกิน ย่อข้อความ ไม่ลดขนาดตัวอักษรต่ำกว่า 8.5pt) · ช่อง 7 วัน ใส่เป็น `<ol>` 7 บรรทัด "งาน · เสร็จเมื่อ" ไม่ต้องเป็นตาราง · ตัวอย่างที่ประกอบเสร็จแล้วดูได้ใน `references/sample-one-pager.html`
6. **บันทึก/แสดงผล ตามที่อยู่:**
   - Claude Desktop / Cowork / Claude Code ที่มีไฟล์: บันทึก `gtm-one-pager.html` ไว้ในโฟลเดอร์งาน (ข้าง my-product.md) แล้วบอก path + "เปิดไฟล์แล้วกด Ctrl/Cmd+P → บันทึกเป็น PDF"
   - claude.ai เว็บ: แสดงเป็น HTML artifact ให้เปิดดูและพิมพ์ได้
   - ถ้าแสดง HTML artifact ไม่ได้: ใส่ HTML ในบล็อกโค้ด ```html ให้ก๊อปไปบันทึกเป็นไฟล์ .html
   - ทุกกรณี: แสดง markdown ฉบับย่อในแชทด้วย (ใช้คู่กับไฟล์ หรือก๊อปไปวางที่อื่น)
7. เสนอข้อความสำหรับช่อง `## 7. Pricing Table` แล้วถามว่า "เขียนลงไฟล์เลยไหม" ตกลงค่อยเขียน + แก้บรรทัด `อัปเดต:` · ไม่มีไฟล์: ถ้าผู้เรียนวาง my-product.md มา แสดง my-product.md ทั้งไฟล์ฉบับอัปเดต (ช่องของ skill นี้แบบย่อ) ในบล็อกเดียว ให้ก๊อปไปแทนของเดิมทั้งก้อน · ถ้าไม่มี my-product เลย แสดงแค่บล็อกช่องของ skill นี้แบบย่อ

## รูปแบบผลลัพธ์
1. ไฟล์/Artifact HTML ตามแม่แบบ
2. Markdown ในแชท:
```markdown
# GTM One-Pager: <ชื่อ Product>
<ทำอะไร 1 ประโยค> · สถานะ: <...> · อัปเดต <วันที่>
**Positioning:** ...
**ICP:** ... | **Value Prop:** ...
**Growth Loop:** ... | **Magnet:** ...
**Content:** ... | **Paid:** ...
**Sales Motion:** ...
**Pricing Table**
| Tier | เหมาะกับใคร | ต่างกันที่ | ราคา |
|---|---|---|---|
| <ชื่อ> [เดา] | ... | ... | [ใส่ราคา] |
**7 วันถัดไป:** ยังว่าง (ทำต่อด้วย action-plan-7d)
```
3. บล็อกช่อง 7 สำหรับ my-product.md:
```markdown
## 7. Pricing Table (gtm-one-pager)
| Tier | เหมาะกับใคร | ต่างกันที่ | ราคา |
|---|---|---|---|
| ... | ... | ... | [ใส่ราคา] |
- ที่มา: ชื่อ Tier และความต่าง = [เดา] ของ AI จาก ICP / ราคา = ผู้เรียนเติมเอง
```

## ห้าม
- ห้ามเสนอราคา ช่วงราคา ส่วนลด หรือ "ราคาที่เหมาะสม" แม้ผู้เรียนขอ (ให้บอกวิธีหาเอง: ถามลูกค้าจริง 5 ราย ว่าตอนนี้จ่ายเท่าไรกับทางเลือกเดิม)
- ห้ามเติมช่องที่ว่างด้วยเนื้อหาที่ AI คิดเอง นอกจาก Positioning ที่ประกอบจากข้อมูลที่มี และโครง Tier ที่ติด `[เดา]`
- ห้ามแต่งตัวเลข ชื่อลูกค้า โลโก้ลูกค้า คำรับรอง
- ห้ามใช้ font, รูป, script จากภายนอกใน HTML
- ห้ามอัปโหลด/แชร์ไฟล์ขึ้นที่ไหนเอง
