## ทำไม Free Tool (หน้า 52-53)
- บทความ = อ่านแล้วรู้ · Tool = ใช้แล้วได้ผลลัพธ์ เปลี่ยนความเข้าใจเป็น Action
- ผู้ใช้มีเหตุผลกลับมาใช้ซ้ำและแชร์
- เลือกปัญหาที่ **เล็กพอจะ Build แต่สำคัญพอจะค้นหา**
- AEO (หน้า 53): AI Search ชอบคำตอบที่คำนวณหรือทดลองได้ · หน้า Tool ควร **อธิบาย Method และข้อจำกัด** ชัดเจน (prototype จึงต้องมีกล่อง "วิธีคิดและข้อจำกัด")

## Interactive Tool กับ Conversion (หน้า 56)
- ตัวเลข 22-42% ในสไลด์ สไลด์ระบุเองว่าเป็น "Benchmark เชิงทิศทาง" · **ห้ามนำไปเป็นคาดการณ์ของผู้เรียน**
- Conversion ขึ้นกับ Intent, Placement และ Value Exchange · ผลลัพธ์เฉพาะบุคคลเป็นเหตุผลให้กรอกข้อมูล

## Scorecard 5 ข้อ (หน้า 57)
1. Pain เกิดบ่อยและค้นหาจริงหรือไม่
2. Input น้อยและได้ Output เร็วหรือไม่
3. Output แชร์หรือฝังใน Workflow ได้หรือไม่
4. เชื่อมสู่ Product หลักอย่างเป็นธรรมชาติหรือไม่
5. ดูแลข้อมูล ความแม่นยำ และต้นทุนได้หรือไม่

การให้คะแนนในปลั๊กอินนี้: ใช่ = 1 · ยังไม่รู้ = 0.5 · ไม่ใช่ = 0 · รวมเต็ม 5
- ข้อ 1 AI รู้ไม่ได้ว่าคนค้นหาจริงแค่ไหน → ตอบ "ยังไม่รู้" เสมอ เว้นแต่ผู้เรียนมีหลักฐาน · บอกวิธีเช็กเอง: พิมพ์คำถามใน Google ดูคำแนะนำอัตโนมัติ, ใช้ Free Keyword Generator (หน้า 54), ถามลูกค้า 3 คนว่าเคยค้นเรื่องนี้ไหม
- คะแนนเท่ากัน: เลือกข้อ 2 (สร้างง่าย) สูงกว่า เพราะต้องสร้างเสร็จในคลาส

## กติกา prototype (ใช้ตอนสร้าง HTML)
- ไฟล์เดียว · CSS/JS inline · **ไม่มี request ออกนอกเครื่อง**: ห้าม CDN, Google Fonts, fetch, API, analytics, ฟอร์มที่ส่งข้อมูลไปไหน
- ฟอนต์: `font-family: system-ui, -apple-system, "Segoe UI", Tahoma, sans-serif` (แสดงไทยได้บนทุกเครื่อง)
- ไม่ใช้ localStorage (artifact บางที่ใช้ไม่ได้)
- ความยาวเป้าหมาย 120-220 บรรทัด · Input ไม่เกิน 5 ช่อง · คำนวณ/ประมวลผลในเครื่องด้วยกฎที่เขียนไว้ชัด
- ค่าตั้งต้นในช่องกรอก = ว่าง · placeholder บอกหน่วย (เช่น "นัดต่อเดือน") ไม่ใช่ตัวเลขตัวอย่าง · ค่าคงที่ในสูตร (อัตรา, ราคา, เปอร์เซ็นต์) ต้องเป็นช่องที่ผู้ใช้แก้ได้ ห้ามฝังตัวเลขที่ AI แต่ง
- ส่วนประกอบ: หัวข้อที่เป็นคำถามที่คนค้น · ช่องกรอก · ปุ่มคำนวณ · ผลลัพธ์ · ปุ่ม "คัดลอกผลลัพธ์" (navigator.clipboard ครอบ try/catch) · กล่อง "วิธีคิดและข้อจำกัด" · ปุ่ม CTA ไป Product (`href="#"` + ข้อความ `[ใส่ลิงก์ Product]`)
- ถ้ามีช่องอีเมล: เป็นแค่ช่องตัวอย่าง กดแล้วขึ้นข้อความ "prototype ยังไม่เก็บข้อมูลจริง"
- responsive บนมือถือ (max-width ~560px, padding 16px)
