# free-tool · เครื่องมือฟรีที่พาคนเข้า Product

อ้างอิง: [references/eam-frameworks.md](references/eam-frameworks.md) (4 แบบ, Scorecard, กติกา prototype) · โครง HTML: [references/prototype-skeleton.html](references/prototype-skeleton.html)

## เมื่อไรใช้
- Block 3.2 (14:25-15:05) หลัง plg-loop · จุด wow ของบ่าย: ผู้เรียนได้เครื่องมือที่กดใช้ได้จริง
- ผู้เรียนอยากได้ lead magnet ที่ไม่ใช่บทความ

## ต้องมีอะไรก่อน
1. อ่าน `my-product.md` ช่อง 1 (ICP, VP, ทำอะไร) และช่อง 2 (Loop) ถ้ามี
2. ไม่มีไฟล์: ขอให้วางเนื้อหา my-product.md หรือตอบ 3 ข้อในข้อความเดียว: Product ทำอะไร · ขายให้ใคร · ลูกค้าเจ็บเรื่องอะไรที่สุด
3. ได้ข้อมูลแล้วผลิตเลย ขาดอะไรติดป้าย `(สมมติ)`

## ขั้นตอน
**ข้อความที่ 1 · ไอเดีย + คะแนน (ห้ามสร้าง HTML ในข้อความนี้)**
1. เสนอ 3 ไอเดีย **ต่างแบบกัน** จาก 4 แบบในสไลด์หน้า 55 (Grader · Generator/Template · Shareable Output · Calculator) · ทุกไอเดียตอบ Pain ใน VP และเล็กพอสร้างเป็นหน้าเดียว
2. แต่ละไอเดีย 1 บรรทัด: ชื่อ · คำถามที่ ICP พิมพ์ค้นหา · Input → Output
3. ตาราง Scorecard 5 ข้อ (หน้า 57): ใช่ = 1 · ยังไม่รู้ = 0.5 · ไม่ใช่ = 0 · รวมเต็ม 5
   - ข้อ 1 (ค้นหาจริงไหม) = "ยังไม่รู้" เสมอ + บอกวิธีเช็กเอง 1 บรรทัด (ดู reference)
4. แนะนำไอเดียคะแนนสูงสุด แล้วถาม: "เลือกข้อไหน (1/2/3) · ตอบ 'ตามที่แนะนำ' ก็ได้"

**ข้อความที่ 2 · spec + สร้างเลย (หลังผู้เรียนเลือก)**
5. Spec หน้าเดียว (ตามรูปแบบด้านล่าง) สั้น อ่านบนจอเดียว
6. สร้าง prototype ทันทีในข้อความเดียวกัน ตามกติกาใน reference:
   - ไฟล์ HTML เดียว CSS/JS inline · ไม่มี CDN/API/fetch/ฟอนต์ภายนอก · UI ภาษาไทย · Input ไม่เกิน 5 ช่อง
   - เริ่มจากโครง prototype-skeleton.html แล้วแทน `{{...}}` ให้ครบ ห้ามเหลือ `{{` ในไฟล์
   - ตัวเลขทุกตัวที่ใช้ในสูตรมาจากช่องที่ผู้ใช้กรอก ห้ามฝังอัตรา/ราคา/% ที่ AI แต่ง
   - มีปุ่มคัดลอกผลลัพธ์ · กล่อง "วิธีคิดและข้อจำกัด" (หน้า 53) · ปุ่ม CTA `[ใส่ลิงก์ Product]`
   - ถ้าของจริงต้องใช้ AI ประมวลผล (เช่น วิเคราะห์ข้อความ): prototype ใช้กฎง่ายแทน (checklist, คำสำคัญ, คะแนนจากคำตอบ) แล้วเขียนในข้อจำกัดว่าเวอร์ชันจริงจะใช้ AI
   - เป้า 120-220 บรรทัด ถ้ายาวกว่านี้ตัดฟีเจอร์ ห้ามแบ่งหลายข้อความ
7. ส่งมอบตามที่อยู่:
   - **มีโฟลเดอร์งาน (Claude Desktop / Cowork / Code):** บันทึก `free-tool.html` ในโฟลเดอร์งาน บอกให้ดับเบิลคลิกเปิดในเบราว์เซอร์
   - **claude.ai เว็บ:** แสดงเป็น HTML artifact
   - ทำไม่ได้ทั้งสองแบบ: ใส่ในบล็อกโค้ด `html` ให้ก๊อปไปบันทึกเป็นไฟล์ .html
8. ลองกดในใจ 1 รอบ: กรอกค่าตัวอย่าง → ได้ผล → ไม่มี error · ถ้ามีเครื่องมือรันโค้ดได้ ให้เปิดเช็กจริง
9. ร่างช่อง "## 3. Magnet: Free Tool (free-tool)" แล้วถาม "ตกลงให้เขียนลงไฟล์ไหม"
   - มีไฟล์: แทนที่เนื้อหาใต้หัว `## 3.` จนถึงหัว `## 4.` เท่านั้น + แก้บรรทัด `อัปเดต:`
   - ไม่มีไฟล์: ถ้าผู้เรียนวาง my-product.md มา แสดง my-product.md ทั้งไฟล์ฉบับอัปเดต (ช่องของ skill นี้แบบย่อ) ในบล็อกเดียว ให้ก๊อปไปแทนของเดิมทั้งก้อน · ถ้าไม่มี my-product เลย แสดงแค่บล็อกช่องของ skill นี้แบบย่อ
10. ปิดด้วยกล่อง "ตรวจก่อนใช้"

ถ้าผู้เรียนพิมพ์มาตั้งแต่แรกว่ามีไอเดียแล้ว: ข้ามข้อ 1-4 ให้คะแนนไอเดียนั้นอย่างเดียว แล้วทำข้อ 5-10 ในข้อความเดียว

## รูปแบบผลลัพธ์
ข้อความที่ 1:
```
| # | ไอเดีย (แบบ, หน้า 55) | คำที่ ICP ค้น | Input → Output |
|---|---|---|---|
| 1 | ... (Calculator) | "..." | ... → ... |

Scorecard (สไลด์หน้า 57)        | 1 | 2 | 3 |
1 Pain บ่อย + ค้นหาจริง          | ? | ? | ? |
2 Input น้อย Output เร็ว          | ✓ | ✓ | ✗ |
3 แชร์/ฝังใน Workflow ได้         | ...
4 เชื่อมสู่ Product หลัก           | ...
5 ดูแลข้อมูล ความแม่นยำ ต้นทุนได้  | ...
รวม (เต็ม 5)                     | 4 | 3.5 | 2.5 |
เช็กข้อ 1 เอง: <วิธี>
แนะนำ: ข้อ <N> เพราะ <1 บรรทัด>
```
ข้อความที่ 2 (spec):
```
ชื่อเครื่องมือ: ... · สำหรับ: <ICP> · ตอบคำถาม: "..."
Input: 1) ... 2) ... (ไม่เกิน 5)
Processing: <สูตร/กฎที่ใช้ เขียนตรงๆ>
Output: <ผู้ใช้เห็นอะไร>
Moment แชร์/กลับมาใช้ซ้ำ (หน้า 58): ...

ข้อจำกัด: ...
```
ช่องใน my-product.md: ชื่อเครื่องมือ · แบบ · คำถามที่ตอบ · Input/Processing/Output ย่อ · คะแนน Scorecard · CTA · ไฟล์ prototype (free-tool.html หรือ "artifact ในแชท")

## ห้าม
- ห้ามสัญญาผล SEO, ยอดคนใช้, จำนวน lead, หรืออ้าง 22-42% (หน้า 56) เป็นคาดการณ์ของผู้เรียน
- ห้ามฝังตัวเลขที่แต่งเองในสูตรหรือผลลัพธ์ · ห้ามแต่งข้อมูลอ้างอิงตลาดในหน้าเครื่องมือ
- ห้ามเรียก API/ส่งข้อมูลออก · ห้ามใช้ไลบรารีภายนอก · ห้ามเก็บอีเมลจริง
- ห้ามแต่งรีวิวหรือ "ผู้ใช้ X คนใช้แล้ว" ในหน้าเครื่องมือ
- ห้ามสร้าง HTML ก่อนผู้เรียนเลือกไอเดีย (ยกเว้นผู้เรียนให้ไอเดียมาเอง)

## กล่อง "ตรวจก่อนใช้"

```
- ส่วนที่ AI เดา: คำที่ ICP ค้น · คะแนน Scorecard ข้อ 3-5 · สูตรใน Processing (ตรวจว่าตรงกับธุรกิจจริง)
- ขั้นถัดไป: พิมพ์ "ทำปฏิทินคอนเทนต์" เพื่อใช้ skill content-matrix (Block 4.1) · เครื่องมือนี้เอาไปเป็นคอนเทนต์ขั้น Consideration ได้
```
